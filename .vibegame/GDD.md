# Game Design Document

> **Version** v2.1（盈亏关联进度 + 导师去反转）| **Type** 剧情化模拟 / 金融扫盲 (Narrative Simulation / Edutainment) | **Platform** Browser (PC/移动) | **Session** 以「章」为单位，单章 15–25 分钟，章内 2–3 个自然停顿点；全程约 3–4 小时
> **One-liner**: 一个纯金融小白也能安心上手的「拟真券商」模拟器——八章生活处境推着你往前走，在零真实金钱风险里，把交易所、银行、基金、期权这些原本吓人的词，变成你能亲手操作并讲清楚的东西。

> ③ **「这个量很合适」**——八章 / 约 3–4 小时的规模**原样通过**，本章表与章节数量**未增未减**。

## Core Fantasy

> 这一刻玩家「赢」了——它该是什么感觉？

**不是「我学会了怎么交易」，而是「我走完了这条路，而且我知道我是怎么走过来的」。**

你从一个把钱放活期、听到「股票」就想起舅舅亏钱的普通人开始。八章里，每一章都是你生活里真实会遇到的一件事：同事在群里晒收益、你想买腾讯却没有港币、你熬夜盯着大洋彼岸的行情、你妈问你「港币跌了你的钱是不是就少了」。你在这些处境里被推着做了决定，而每一次决定背后都有一条你此前不知道的规则。

走到最后，你打开一个和真实券商几乎一样的界面，能看懂一根 K 线，敢下一单，能对自己说出「我为什么赚了 / 亏了」，也能在别人劝你「全押这个」的时候说出一句「我先只放 5%」。**你不再是被市场吓退的旁观者，而是走完了一整条入门路的过来人。**

本作的「赢」不是战胜别人、不是账户翻倍，而是**理解 (Understanding)** 加上**走完 (Completion)**。情绪落点属于 MDA 中的 **Discovery（发现）/ Narrative（陪伴叙事）/ Serious（严肃成长）/ 轻度 Challenge（解惑的爽感）**，而非 Sensation / Domination。这一点贯穿全篇所有设计决策。

> **v2.1 的落点变化**：核心幻想里多了**一层诚实**——你的账户**真的会说话**。它在每一章末给出一个评级（A/B/C/D），在结业证书上留一行字。「理解」决定你能不能毕业，「成绩」决定你被记成什么样子（见 D-24 替换条目与 `### 章末结算与评级`）。这不是把游戏变成盈利竞速：盈亏不发钱、不改市场、不挡路；它只是**不再假装盈亏不重要**——而这恰好是《入市第一课》最该有的诚实。

> **v2.0 的落点变化**：v1.0 的 Core Fantasy 是「幕布被拉开」——一个**瞬间**的顿悟。v2.0 改成「一条路走完」——一个**有过程**的改变。前者是发现，后者是成长叙事；两者不冲突，但后者需要一条线性主线才能承载。

## Game Overview

### Design Pillars

- [x] **主线牵引（线性但不剥夺选择）**——玩家的下一步永远有来处、有理由、有去处；线性用来决定「先遇见什么」，不用来决定「必须怎么做」。玩家在每一个处境里仍然自己选标的、选数量、选时机。
- [x] **认知安全（心理零风险）**——失败只能教学，不能惩罚；没有真钱、没有 Game Over、没有扣分重玩。
- [x] **真实操作逻辑**——学的是真券商/交易软件的工作流，日后开真户不陌生。券商 App 是**处境里的工具**，不是菜单。
- [x] **规则即教学**——每条市场规则的差异本身就是一个教学瞬间，而非无意义的摩擦。
- [x] **自主节奏**——章内以「回合制交易日」推进，节奏玩家掌控，随时停下来查词典、看讲解、离开去上班。
- [x] **进度来自理解，成绩来自盈亏**（v2.1 替换原「进度来自理解，不来自盈利」）——能否进入下一章**只看理解确认**（看懂了就走得动；亏了钱也能走完全程、也能毕业）。但账户盈亏**决定你「怎么走」以及「毕业时被记成什么样」**：章末评级决定下一步是走一段**进阶加演**、还是常规推进、还是先做一次**补救节拍**，并在结业证书上留下评定。盈亏**不发钱、不改市场、不挡路**，但它**绝不只是一行装饰**（见 D-24 替换条目、`### 章末结算与评级`）。
- [x] **由浅入深的分层解锁**——七类品种都在框架内，但按「理解程度」逐章放出，而非一次性砸给小白。

### Design Philosophy

1. **信息透明**：市场的随机性必须可见、可解释。我们采用「圈内完美信息」——行情由**可解释的事件**驱动，绝不藏暗随机（honor the game contract，见 `game-fairness.md`；information-design 完美信息亚型）。**线性主线不例外：它只决定「你先遇见哪条规则」，绝不隐藏当下的状态、价格或原因。** 玩家随时能看到自己在第几章、这一章要什么、为什么价格在动。**v2.1 把这条契约补成「没有例外」**：① 老周的隐藏层被移除（见 D-26 替换条目）——他每一章都直接说出「我现在在教你什么、为什么」，导师不再是唯一的信息暗箱；② 章末评级的**公式、阈值与三项输入全部对玩家公开**（结算面板逐项展开），评级绝不是一个说不清的黑箱分数。
2. **因果可见**：每一笔盈亏都有归属（哪个标的、哪条新闻、哪种操作）。复盘不是「你赢了/输了」，而是「你学到了什么」。
3. **教学内嵌**：学习是游戏本身，不是贴在外面的说明册（Koster：游戏是低风险学习工具，停止教学就停止有趣）。
4. **处境先于知识**：先给玩家一个**非知道不可的处境**（我买不起茅台怎么办？我的港币为什么会缩水？），再给知识。知识被需要时才被教，因此被记住。线性主线的全部价值就在这里——它生产「需要」。

### Core Settings

**Art Style**: 混合——交易界面为「拟真券商 App 风」（深色专业 UI，由代码/CSS/SVG 绘制）；关键角色与场景为「温暖手绘风」位图（AI 生成）。冷峻的金融世界 vs 温暖的导师，形成有意对比。

**Game Type**: 剧情化模拟 / 决策模拟 / 教育 (Narrative Simulation / Decision Simulation / Edutainment)

**Atmosphere**: 一半是生活，一半是行情——**温暖日常（银行柜台、深夜书桌、同事的群聊）**与**冷峻行情（深色券商 App、K 线、红色绿色）**交替出现。整体基调：专业但安心、克制而温暖 (Professional yet reassuring)。

**Background Vibe**: 一个把「真实交易所生态」搬进手机/浏览器的安全沙盒——但你不是被丢进去自由探索的，你是被一段生活带进去的：有人在旁边坐着，你是被推着往前走了八步，然后发现自己懂了。

**Player Character**: **玩家本人（第二人称「你」）+ 给定的生活处境**。不设具名角色、不设 avatar 立绘、不设性别与外观；但主角有**写好的处境**：毕业三年、一线城市工作、月薪约 ¥9,000、三年攒下 ¥100,000、有一个总在家庭群里转发财经小道消息的舅舅、有一个爱晒收益的同事。玩家以第一视角操作券商 App，被故事以「你」称呼。

> **为什么是「玩家本人 + 给定处境」而不是具名虚构角色**：具名角色自带距离，会削弱「技能迁移到真实开户」这一核心价值（Magic Circle，见 `core-frameworks.md`——游戏内角色越接近真实角色，圈外迁移越强）；而纯粹无设定的「你」会退回沙盒，没有可写的场景。折中做法是：**身份可代入，处境可书写**。第二人称还能让导师直接对「你」说话（「你上个月问我……」），这是最便宜也最强的线性连续感来源。

**Game Objective**: 走完八章生活情境，在每一章里亲手做一件与钱有关的事、弄懂它背后的规则，直至「毕业」（解锁并理解全部七类品种 + 知道交易所、银行、券商各自在做什么）。

### MDA Framework

**Target Aesthetics (feelings)**：

| Feeling | Weight | How to deliver |
|---------|--------|----------------|
| Discovery（发现/理解） | ★★★★★ | 每章只用一条新规则解释一个生活处境；「原来如此」的瞬间 |
| Narrative（陪伴叙事） | ★★★★ | 八章的生活主线 + 老周从「手把手」到「交还」的弧线；**v2.1：情感重量落在玩家自己的账上**——六次章末评级 + 期末净值与第一章那张活期存单的对照 + E.2 里一章一句念出的「你走过的每一章」 |
| Serious / Expression（成长） | ★★★★ | 从「怕钱」到「懂钱」的自我改变，被一章一章地可见化；**v2.1：这条弧线现在有数字**（六次评级 + 调整后累计收益） |
| Challenge（解惑爽感） | ★★→★★★ | 解开「为什么被拒单/为什么亏」的轻度谜题；**v2.1 新增章末评级**，把「我这一章把钱管成什么样」变成一个可被回答的问题——但挑战仍属 **skill-dominant**，且**只影响怎么走，不影响能不能走** |
| Sensation（刺激） | ★★ | 加密章的极端波动、期权归零的戏剧性——**只作为风险教育的材料，不作为目标** |

> **v1.0 → v2.0 的关键变化**：Narrative 从 ★★ 升到 ★★★★。v1.0 的「导师陪伴」是弱叙事（一个对话框），撑不起线性主线；v2.0 把它升级为「生活处境 + 人物弧线」，才发现足够支撑整局的推进力。
> **v2.0 → v2.1 的关键变化**：Challenge 那一格不再只是「解惑」。用户要求进度与盈亏相关联，于是「我这一章赚了还是亏了」成为一个真实存在、可被回答、且会被记住的问题。**但我们刻意把这份挑战的重量压在「怎么走」而不是「能不能走」上**——因为一个把破产变成 Game Over 的设计，会让小白学到恐惧而不是素养（`feedback-loops.md`、`player-motivation.md`）。

**Derived Dynamics (player behaviors)**：
- 玩家进入一章 → 遇到一个处境并**感到有必要搞懂它** → 在券商 App 里做一件具体的事（读单子 / 比两个产品 / 下合规的单 / 硬撞一次拒单）→ 看到结果与原因 → 听老周解释或提问 → 章末复盘 → 拿到「已理解」确认 → 看到下一章的名字，想知道是什么 → 继续。
- 偶发但重要的动态：玩家在章内**偏要买别的**（老周建议买工行，他偏要买宁德时代）→ 结果变好或变坏 → 老周都不拦，只点评 → 玩家意识到「没人管我」→ 更愿意认真想。

**Supporting Mechanics**：
- **线性章节推进 + 章内目标卡**（情境牵引与可见的下一步）
- 回合制交易日 + 事件驱动行情（可见因果）
- 概念词典 + 老周的提问式引导（随时可查，非侵入）
- 分层解锁 + 章内节拍（渐进挑战）
- 每日复盘 / 盈亏归因（可见因果）
- 安全失败（拒单/亏损转为教学）
- 自由交易日窗口（章间沙盒，容纳玩家的试验欲）
- **章末结算与评级（v2.1：把「我这一章把钱管成什么样」变成一次可见、可复盘、且**只影响怎么走**的反馈）**

> 理论依据：MDA 自顶向下（目标体验 → 所需动态 → 对应机制，见 `core-frameworks.md`）；目标层级分解（主线目标→章目标→节拍目标→单笔交易，见 `core-frameworks.md` 的 Goal Hierarchy Decomposition——v1.0 只有「单笔交易」这一层，缺中观与主线目标，因此玩家容易迷失，这正是本次改版的直接动因）；Four Types of Fun 中本作以 **Easy Fun（好奇探索）+ Serious Fun（自我改变）+ Narrative** 为主、轻度 Hard Fun（解惑），刻意不依赖 People Fun（单机自学，见 `player-motivation.md`）。Bartle 玩家类型中本作服务 **Explorer（探索/理解世界）** 主导型，但线性主线额外照顾了 **Achiever** 的路径需求（见 `player-types.md`）。

### Signature Mechanics

1. **「生活处境 → 非懂不可 → 亲手操作 → 章末复盘」的章内闭环**：每一章都从一个玩家生活里真实会撞上的处境开始（同事在群里晒收益、你想买腾讯却没有港币、凌晨一点美股刚开盘），处境生成「需要」，需要驱动学习，学习落在一次真实的操作上，操作的结果在章末被拆解。这是本作区别于「教程 + 模拟器」组合的核心：**教学不是被安排的，是被生活逼出来的**。
2. **「进入下一交易日」的回合制市场**：玩家点击才推进，行情由可解释事件驱动并结算。它把「真实市场的时间压力」抽走，只留下「观察→决策→看见结果→理解原因」的纯净学习环（flow 状态：去掉时间焦虑）。**v2.0 中它同时在两个层级运行**——章内它是节拍推进器（老周说「明天再看」，玩家点一下），自由交易日里它是 v1.0 的沙盒节奏（玩家想推几天推几天）。
3. **盈亏归因复盘**：不止显示赚亏多少，而是把结果拆到「标的 × 事件 × 操作」，让玩家真正看懂因果。线性结构的加入让它更强：复盘还能说「你在这一章学的东西，和你这一笔亏损的关系是……」。这是本作区别于普通模拟炒股的核心。
4. **老周的提问（而非讲解）**：每当玩家遇到新概念或被拒单/亏损，老周给的是一个可以在 10 秒内回答的选择题（「你觉得这条规则是限制你，还是保护你？」），两个选项都有回馈，不判对错。玩家不是被讲，是被问。这同时是「理解确认」的主要手段——答什么都推进，但答完之后的对话不同（见 `challenge-design.md` 的 assist system：可选、渐进、非侵入）。

### Core Game Loop

**v2.0 是三层嵌套的环，不是一层。** v1.0 只有最内层（交易日环），玩家在里面重复却没有方向，最终会觉得「一直在看图表」——这是用户提出改版的根本原因。**v2.1 在章末补上一格「章末结算」（评级 → 加演 / 常规 / 补救），让「我这一章把钱管成什么样」成为主线环上第二次可见的反馈**（第一次是章末复盘回答「我懂了什么」）。

```
【主线环 · 一局的形状（约 3–4 小时，8 章）】
   [一章开场：一个生活处境 + 老周出现]
              │
              ▼
      ┌──────────────────────────────┐
      │  【章内节拍环 · 15–25 分钟】    │
      │                              │
      │  [节拍：处境升级 / 需要新认知]  │
      │            │                 │
      │            ▼                 │
      │  [玩家在券商 App 里做一件事]   │◄──┐
      │   （读单子/比产品/下单/撞拒单） │   │
      │            │                 │   │
      │            ▼                 │   │
      │  [看到结果 + 原因 + 老周提问]  │   │
      │            │                 │   │
      │            ▼                 │   │
      │  [章末复盘：你学到了什么]      │   │
      └────────────┬─────────────────┘   │
                   │                     │
                   ▼                     │
  [章末结算：本章净值变化 → 评级 A/B/C/D]   │
                   │                     │
        ┌──────────┴──────────┐          │
        ▼                     ▼          │
  [A：进阶加演节拍]   [D：补救节拍（必过）]  │
        └──────────┬──────────┘          │
                   ▼                     │
       [章末确认：理解了 → 解锁下一章]      │
                   │                     │
                   ▼                     │
       [自由交易日窗口：想玩几天玩几天] ─────┘
                   │
                   ▼
       [下一章开场 / 或进入尾声 · 毕业]
```

**最内层的「交易日环」（v1.0 原样保留，成为节拍环的下属循环）**：

```
[新交易日开始] ──► [行情跳动 + 新闻事件卡弹出]
                        │
                        ▼
              [玩家观察: 自选行情 / K线 / 新闻]   ← 可随时查词典 / 呼叫老周
                        │
                        ▼
              [玩家决策: 下单(限价/市价) 或 观望]
                        │
                        ▼
              [撮合 + 当日结算: 持仓/现金/费用更新]
                        │
                        ▼
              [点击「进入下一交易日」] ── 回到顶部
                        │
                        ▼ (日终，可选)
              [每日复盘: 净值曲线 + 盈亏归因 + 老周点评]
```

**Loop duration**：
- 主线环：全程 3–4 小时，8 章。
- 章内节拍环：单章 15–25 分钟，含 3–5 个节拍、2–3 个自然停顿点。
- 交易日环：单个交易日玩家自控，通常 1–5 分钟。「天」本身在点击瞬间完成，无实时等待。

**Loop 要素映射（core-loop 理论，见 `core-frameworks.md`）**：
- 最内层：Action=观察+下单决策；Feedback=撮合结果/价格变动/新闻解释；Reward=净值变化；Repeat=下一交易日。
- 节拍环：Action=处理一个处境；Feedback=结果 + 原因 + 老周的提问；Reward=概念卡解锁 + 老周的态度变化；Progression=章内节拍推进；Repeat=下一个节拍。
- 主线环：Action=活过一段生活；Feedback=章末复盘（这一章你做了什么、懂了什么）+ **章末结算（这一章你的钱变成了多少 → 评级 A/B/C/D）**；Reward=章节确认 + 新工具（新交易品种）+ **老周按评级给的一句话（加演 / 评语 / 补救）**；Progression=下一章；Repeat=直到毕业。

**目标层级分解（v1.0 缺失的部分，本次补齐）**：

| 层级 | 内容 | 例子 |
|------|------|------|
| 主线目标 | 走完八章、毕业 | 「我要把这些搞明白」 |
| 中观目标 | 完成当前章 | 「这一章我想知道 ETF 到底是个啥」 |
| **成绩层（v2.1 新增）** | **本章把钱管成什么样** | **「这一章我不想拿到『再摆一次』」** |
| 子目标 | 完成章内节拍 | 「我要在这两个产品里选一个」 |
| 微观目标 | 成功完成一次操作 | 「把这一单下出去」 |

> **成绩层为什么必须存在（v2.1）**：用户要求「进度与盈亏相关联」。若盈亏不落在任何一层目标上，它就只是一行装饰。把它放在**中观与子目标之间**——比「这一章要搞懂什么」更具体，比「这个节拍要做什么」更宏观——恰好是玩家在章中后段自然会产生的问题：「我这一章到目前为止，做得怎么样？」它同时是 flow 通道的**反馈来源**：没有它，玩家在章内只能感知到「我懂没懂」，感知不到「我做得好不好」。

> **每一层都必须自己能产生满足感**（`core-frameworks.md`：「The loop itself should be fun, not merely a means to an end」）。因此每一章的章末确认本身就是一次小小的收束快感，而不只是「解锁下一章的门票」。

## 线性主线设计 (Linear Spine Design)

> 本节回应用户要求：「我想要是一个线性的互动类游戏而不是单纯的图表等」。

### 选定的形式：**生活情境章节 + 章内任务节拍（混合体）**

**一句话**：全剧分八章，每章是一段**玩家生活里真实会遇到的处境**（不是一关谜题）；章内由 3–5 个**节拍**构成，每个节拍教一个概念、要求玩家亲手做一件与之匹配的事；章与章之间用一个**自由交易日窗口**放开手脚。

**为什么是这个形式（认真权衡过的四个选项）**：

| 选项 | 优点 | 为什么不够 / 如何被吸收 |
|------|------|----------------------|
| **A. 章节化生活情境** | 处境生成动机；能写情感；知识被需要时才被教 | **采用为主干** |
| **B. 关卡/任务阶梯**（每关一个概念 + 一个可验证目标） | 结构清晰、可验证、易实现 | **被吸收为「章内节拍」**。纯阶梯缺少情感重量，八关下来像八道题，撑不住 3 小时；且容易写成「照做即过关」，与「理解」的目标错位 |
| **C. 视觉小说主线 + 几处关键抉择** | 叙事密度高、成本低 | **被吸收为「章内关键表态点」**。纯 VN 会把玩家从券商 App 里请出去，而「真实操作逻辑」是本作支柱；操作本身必须留在主线里 |
| **D. 沙盒 + 任务链** | 自由度高、玩家不憋屈 | **被拆散为「章内自主 + 章间自由窗口」**。这正是 v1.0 的形态——用户已明确否决：没有主线牵引时，初学者会「一直在看图表」而不知道自己在学什么 |

**理论依据**：

1. **目标层级分解（`core-frameworks.md`）**：v1.0 只有「微观目标（下这一单）」与薄弱的「主线目标（毕业）」，中间是空的。玩家不知道「现在该干嘛」，于是只能反复看图表。章节结构直接补上「中观目标（这一章要搞懂什么）」与「子目标（这个节拍要做什么）」两层。**这是本次改版最硬的理论理由。**
2. **flow 通道（`player-motivation.md`）**：沙盒没有难度曲线——玩家自选的挑战要么太低（无聊地乱点）要么太高（懵着亏钱）。八章是一条**作者调过的难度曲线**，把玩家持续留在 flow 通道里。
3. **chunking（`player-motivation.md`）**：一章一个核心概念，节拍是更小的块。小白不会一次面对七类品种、九条拒单规则、五套费用公式。
4. **Koster 的低风险学习（`player-motivation.md`）**：游戏之所以有趣是因为它在教；线性主线保证**教学永不停止**（每一章都还有新东西），这是避免「重复 → 无聊」的结构性解药。
5. **辅助系统三原则（`challenge-design.md`：可选 / 渐进 / 非侵入）**：线性主线本身就是一个**宏观辅助系统**——它替玩家决定「现在该练哪个技能」。而老周的引导是**微观辅助系统**，必须保持可折叠、不打断、可静音。
6. **信息设计（`information-design.md`）**：线性 ≠ 隐藏信息。本作的「完美信息」契约不变——主线只决定**引入顺序**，玩家对当前价格、事件、持仓、原因的可见性与 v1.0 完全一致。
7. **游戏公平（`game-fairness.md`）**：不得有隐藏惩罚。因此「章内失败」必须是可见的、可立刻重来的，且不给任何惩罚（详见「进度、失败与结局」）。

### 线性与自由之间的张力：如何解决（这是本设计的核心难题）

用户的诉求里有一个天然矛盾：**线性主线提供动机与顺序，但过刚的主线会剥夺「学习真正发生」所需的自主性**——被牵着走的人不会形成判断力，只会形成顺从。

**我们的解法：把「下一个处境」写成给定的，把「这个处境里怎么做」写成完全自由的。**

具体规则（R1–R4 为 v2.0 原文，**v2.1 一字未改**；R5 为 v2.1 新增）。实现者照此判断任何新加互动是否合规：

| 规则 | 说明 | 反例（违规做法） |
|------|------|-----------------|
| **R1 章给处境，不给动作** | 章节只规定「你现在面临什么」与「这一章结束时你要能说清什么」，不规定玩家买哪只、买多少、哪天买 | ❌「请买入 601398，数量 100 股」 |
| **R2 出场条件是理解验证，不是操作验证** | 验证方式 = 用一个 10 秒能答的选择题/一次自由操作的结果，答什么都推进 | ❌「必须买入并持有 3 个交易日」 |
| **R3 章内不锁 UI** | 老周的建议用**视觉强调**（高亮、批注）呈现，绝不用禁用按钮或灰色遮罩。玩家买错标的、买反方向、什么都不做，都能继续 | ❌ 把茅台那一行置灰 |
| **R4 偏离被点评，不被阻止** | 玩家做了和引导不同的事，老周的反应是**点评后果**（「你买了宁德时代——它今天上下摆了 8%，你手抖了吗？」），不是纠正 | ❌ 弹窗「建议按导师指引操作」 |

> **R1–R4 在 v2.1 一字未改**，它们是「线性不剥夺选择」的完整保证。v2.1 只在其后追加一条，用来承载用户新批准的「进度与盈亏相关联」：

| 规则 | 说明 | 反例（违规做法） |
|------|------|-----------------|
| **R5 成绩不挡路，成绩决定路的样子（v2.1 新增）** | 账户盈亏**永远不是**「能不能走」的条件。它只决定「**怎么走**」：A 级 → 本章末尾追加一段**进阶加演节拍**；B/C 级 → 常规推进；D 级 → 先完成**一次必过的补救节拍**再推进。评级**不影响行情、事件抽取、事件幅度、费率、涨跌停、撮合与解锁条件**（反正反馈锁 L2/L3，见 `### 章末结算与评级`） | ❌「本章盈利 ≥5% 才能进入第三章」<br>❌「亏钱的玩家下一章事件幅度加倍」<br>❌ 评级为 A 时发放奖励金 / 手续费折扣 / 更大仓位上限 |

> **张力结论**：玩家失去的是「我现在该干嘛」的自由（这恰好是初学者最不需要、也最容易迷失的自由），保留的是「我怎么做」的全部自由（这才是判断力的训练场）。引用 `challenge-design.md`：本作的挑战属于 **skill-dominant**，而 skill-dominant 游戏的正解就是提供辅助系统，不是提高门槛。
> **R5 与 R2 的关系（实现者必读）**：R2 规定「出场条件是理解验证，不是操作验证」——这条**没有被推翻**。D 级追加的补救节拍**也是理解验证**（老周带你拆账 + 一道 10 秒选择题，答错只重讲），它不检查你的盈亏数字，只延长了一次「再讲一遍」。**因此 R5 不构成对 R2 的例外，只是给它加了一个触发条件。**

### 导师在主线里的行为（周老师 / 老周）

老周从「一个对话框」升级为**贯穿全剧的在场人物**，他的弧线就是玩家的弧线。**v2.1：他没有任何隐藏层**——他的弧线讲的是他**功能的变化**（手把手 → 给选项 → 退到身后 → 直言 → 敬畏 → 交还），不是身份的秘密。

**他在不在场**：**前四章他在场**——不是一个头像面板，而是一个**你约得到的人**（你在银行大厅遇到他、他在你对面喝咖啡、他约你吃了顿饭）。**第五章起他退到「随时可呼出」**——因为那时你已经能自己看懂了，他的退场本身就是成长的证明。

**他什么时候开口（穷举，不多不少）**：
1. **章开场一次**：一句把当前处境点出来的话（「你说你舅舅炒股亏了钱——他亏的其实不是钱，是不知道怎么亏的。」）
2. **节拍推进时**：只在玩家**第一次**遇到某个概念、或某个概念被该节拍点名时。
3. **玩家被拒单 / 亏损 / 触警示线时**：先安慰一句，再解释，最后提问。绝不说「你不该……」。
4. **章末一次**：收束 + 一句留下的话（往往预告下一章的气氛）。
5. **玩家主动呼叫时**：任何时候都能点开，问「这是什么意思」「我该怎么办」。**注意：他给视角，不给答案**（「我该怎么办」的回答永远是「我们先把这两件事摆一起看看」）。

**他怎么教而不唠叨**（`challenge-design.md` assist 三原则的具体落地）：

| 原则 | 落地做法 |
|------|---------|
| **可选** | 老周的所有非剧情发言都可以折叠/静音；玩家在设置里可以关掉「主动提示」，只保留剧情对白 |
| **渐进** | 同一概念他最多主动讲 2 次（第 1 次给比喻，第 2 次给机制）；第 3 次起只在玩家呼叫时出现 |
| **非侵入** | 玩家在**自由交易日**或章内自由操作时，他**绝不**主动弹窗（唯一例外：触发风险警示线） |
| **提问优先** | 每一次讲解都以一个可在 10 秒内回答的选择题结束。玩家必须点一下，才能继续。这让教学变成**互动**而非**广播** |
| **留白** | 他从不把**答案**直接给你：「这条规则保护的是谁，你先想想。」——**留白留的是「你自己得出结论的那一步」，不是剧情悬念。** v2.1 明确：他**不留任何关于他自己或关于未来的悬念**，一句「下一章你会知道」指的是**下一章会教的机制**，不是任何人的秘密 |

**他的弧线（六段，与八章对齐）**：

> **v2.1 变化**：原七段弧线中的「揭晓」被删除（用户裁决：「导师不要隐藏」）。弧线本身**仍然存在**——它讲的从来不是秘密，而是**他的功能变化**：从牵着你的手，到你不需要他的手。这一段弧线在 v2.1 里变得更干净，因为它不再需要为一次反转做铺垫。

| 阶段 | 章 | 他的状态 | 玩家的状态 |
|------|----|---------|-----------|
| 牵引 | 1–2 | 他在场，手把手；他说话最多，你只需照做 | 跟着走，安全感 |
| 松手 | 3–4 | 他开始给选项而不给答案：「这两样你想先看哪个？」 | 第一次自己选，有点慌 |
| 退后 | 5–6 | 他不在场了，只在你呼叫时出现。你搞砸了他也不拦 | 试着自己判断 |
| 直言 | 7 | 「我拦不了你，我只能让你先写下你的底线」——**他当场把这条规矩为什么存在讲清楚，不卖关子** | 第一次感到「原来他也是个人」 |
| 敬畏 | 8 | 「这个，我会怕。」——**他紧接着就说明他为什么怕**（「我见过太多人在这个东西上把十年积蓄交出去。我说怕，是因为我知道它有多快。」），当场讲完，不留悬念 | 对杠杆生出真正的敬畏 |
| 交还 | 尾声 | 他把词典与账户交还给你，并把**你走过的每一章**念给你听（见 `### 尾声 · 毕业` E.2） | 你可以自己走了 |

**他不藏事（v2.1 替换原「他的隐藏层」）**：

用户裁决：**老周不要隐藏层、不要反转、不要延迟揭晓。** 他从头到尾是一个**直接、透明、功能明确**的老师。因此：

- **他被删除的东西**：年轻时「以为自己懂了」并付出代价的往事、第一章「我以前也这么想」、第四章「我在这三栋楼里待过很久」、第六章「我也有过天天半夜起来看盘」，以及**那杯从第一章到第七章始终满着、一口没喝的咖啡**（这个视觉线索的原用途是埋伏笔，v2.1 连同它的语义一起删除；咖啡杯作为日常道具保留，但**不再具有任何第二层含义**）。
- **他为什么只教「看懂规则」和「不要预测」**：因为这两条就是本作最核心的两条教学内容，不需要任何个人往事来解释。**他会直接把这句话说出来**：「我为什么总说不要预测？因为在这八章里，你没有一次能提前知道明天的新闻。这不是我藏着什么，这是市场本身的样子。」
- **他每一次出现的目的都是可见的**：他讲一个概念时会明说「你现在需要懂这个，因为……」。**不藏动机、不藏身份、不留后手。**
- **设计上的收益（这不是一笔净损失）**：Design Philosophy 第 1 条承诺「信息透明，绝不隐藏」，而 v2.0 里**导师的隐藏层恰恰是这条契约唯一的例外**——一个藏了七章的老人。移除它之后，本作的信息透明契约**第一次做到没有例外**。一个不藏事的老师，玩家也更容易信他；而「信他」正是全剧八章推进力的来源。

### 主线与自由交易工具如何共存

用户明确说过「核心玩法为模拟交易，你也可以在此基础上设计新的玩法」，因此券商 App 被**完整保留**，只是换了位置：它从「整个游戏」变成「主线里的工具 + 主线外的沙盒」。

**三种状态，切换权永远在玩家手上**：

| 状态 | 什么时候 | 券商 App 的权限 | 主线的状态 |
|------|---------|----------------|-----------|
| **章内模式** | 正在走某章节拍 | 已解锁的全部品种可自由交易；老周的建议以高亮呈现但不锁 UI（R3） | 目标卡显示「本章要什么」，不可跳过 |
| **自由交易日窗口** | 每章结束后（以及章内玩家主动选择时） | 与章内相同，但**不推进任何章**；事件池继续消耗；可连续玩任意多个交易日 | 一张「回到主线」的卡片常驻，显示下一章名字与一句话预告 |
| **纯自由模式** | 全局菜单随时可切 | 与 v1.0 沙盒**完全一致**：无目标卡、无引导、想干嘛干嘛 | 挂起；可随时点回 |

**不会 railroad（推着走）的三个保证**：
1. 出场条件是理解验证而非操作验证（R2）——玩家的操作没有任何一次是「必须按按钮 A」。
2. 章内 UI 永不锁定（R3）——玩家可以在讲 ETF 的那一章偏去买茅台。
3. 偏离被点评不被阻止（R4）——老周的权威来自「他说的准」，不来自「他拦得住」。

**不会丢主线（散架）的三个保证**：
1. **能不能推进，只由章节确认驱动**（R5）：章节的**进入与推进**从不由账户余额决定——玩家在自由模式里赚翻或亏光，章进度一格不动。v2.1 新增的是：**章内**的钱会决定你**用什么方式**离开这一章（加演 / 常规 / 补救），但它同样不阻止你离开。
2. 下一章名字**永远可见**（挂在自由窗口的常驻卡片上），玩家随时知道「主线还在那儿」。
3. 从自由模式回到主线时，老周给一句**承接语**（「玩够了？我们继续。」/「你刚才那几笔我都看见了。走吧。」）——一句话就把散掉的线重新接上。

> **沙盒仍然是干净的心理避风港（v2.1 强化）**：我们**依然不做**「自由模式的盈亏影响主线难度」这类自适应机制（理由见 `feedback-loops.md`：那会让「越亏越难」形成正反馈崩坏，也会让玩家觉得玩沙盒是在被算分）。v2.1 只是把这条界线画得更明确：
> - **自由交易日窗口与纯自由模式的盈亏，不计入任何章节评级**——所以玩家在沙盒里怎么试都不会改变下一章「怎么走」。沙盒可以完整承接试验欲。
> - 它们**会计入结业评定里的「全程调整后累计收益」**，因为那份记录必须诚实。这是一处刻意的取舍：**沙盒里的行为不影响推进，但会被如实记进你自己的成绩单。**

### 第一章开场设计（逐拍，含对已知缺陷的修复）

**设计硬约束**：从游戏开始到「第一单成交」之间，**不允许出现任何可能失败的操作**。第一个可能失败的交互出现在第二章。第一章的「不确定」只以「事件造成的价格浮动」形式出现，且必须有老周解释。

#### 已知缺陷（测试发现，本次必须修复）

> 当前实现中，第 1 个交易日默认选中的是最贵的标的**贵州茅台（¥1,408）**，1 手 = ¥140,800 > ¥100,000。玩家的**第一次下单尝试直接失败**（拒单 #1 资金不足）。作为「第一课」，这是灾难性的——小白在 30 秒内学到的是「我连下单都不会」。

**修复方案（三条同时生效）**：

1. **默认选中改为「买得起的第一只」**：自选列表加载完成后，默认高亮的是**按「1 手金额 ≤ 可用资金」筛选后价格最低的那只**（当前数据下 = 工商银行 601398，1 手 ≈ ¥620）。茅台仍在列表里，但它不再是被选中的那一行。
2. **自选列表新增一列「1 手约 ¥XXX」**：让「100 股 = 1 手」这个门槛在**列表上就可见**，而不是等下单时才撞上。玩家第一次看行情时就能自己比较出「哪只我买得起」。
3. **茅台成为「看得见的对比」而不是陷阱**：它的「1 手约 ¥148,000」标红（超出当前资金），玩家看到会自然产生那句「原来买股票不是想买多少买多少」——**这才是这个教学瞬间应该有的情绪，而不是挫败。**

> 注：第 2 条与第 3 条是**呈现层**要求，不改变任何数据或规则；「1 手金额」由现有价格 × 每手股数派生，无需新增数据源。

### 章末结算与评级（v2.1 新增：盈亏如何影响进度）

> 本节回应用户裁决「**进度与盈亏相关联，同时这个量很合适**」。v2.0 的「进度不看钱 / 亏光也能毕业」被**否决并替换**（见 D-24 的替换条目）。本节给出完整机制、公式、阈值与恢复路径。**实现者照此实现，不得自行发明机制、不得自行调参。**
> 用户同时批准了八章规模不变（「这个量很合适」），因此本节**不新增也不删减任何章节**。

**一句话**：章节**能不能**推进，仍由理解确认决定（这条不变，也是本作不会变成盈利竞速的原因）；但**你在这一章里把钱管成什么样，决定你「怎么推进」以及「毕业时被记成什么样」**。

**评级对象与评级窗口**
- 评级**只统计「章内官方节拍期间」的账户表现**。
- **第一章与第四章不参与评级**：第一章是「第一单必须成功」的教学章，第四章是不要求任何交易、不新增品种的呼吸章。两章的**章目标卡上都明写「本章不打分」**——这是公开规则（`game-fairness.md`：不得有隐藏规则）。
- 因此全剧共 **6 次评级**（第二、三、五、六、七、八章各一次；第一、四章不打分），结业评定据此计算。
  > **勘误（2026-09-17）**：原文写「7 次评级（第二至第八章）」，但第四章明确不参与评级，故实际为 **6 次**。**实现时不得硬编码分母**——只统计实际记录到的 `chapterGrades`，门槛 `A ≥ 4` 与 `A + B ≥ 4` 是**绝对次数**，不随分母变化。
- **自由交易日窗口与纯自由模式的盈亏不计入任何章节评级**（沙盒仍是干净的心理避风港，见 `### 主线与自由交易工具如何共存`），但计入结业评定的「全程调整后累计收益」。

**三项输入（全部是钱，全部对玩家可见）**

| 输入 | 定义 | 说明 |
|------|------|------|
| 章内调整收益 `rar` | `(NAV₁ − I − NAV₀) / NAV₀` | `NAV₀` = 本章第一个交易日开始时的 NAV；`NAV₁` = 本章最后一个交易日结束时的 NAV；`I` = 本章内「补足本金 / 重置账户」带来的现金净增加。**剔除外来入金**——所以在章内补过钱既不能刷分，也不会被倒扣。 |
| 章内最大回撤 `maxDD` | `max_t ( (峰值调整NAV − 调整NAV_t) / 峰值调整NAV )` | `调整NAV_t = NAV_t − 截至 t 的累计外来入金`。回撤衡量「过程的代价」，与收益分开计——**大起大落后回到原点，也是一种要学的失败。** |
| 章内成本比 `costRatio` | `章内累计交易费用 / 章内累计成交金额` | 分母用**成交金额**而非本金，因此这项惩罚只与交易习惯有关，**与资金量无关**（防止穷玩家被结构性惩罚）。 |

**公式与阈值（实现者照此）**

```
S = clamp( 50 + rar × 833 , 0 , 100 )                    // 0% 净值变化 = 50 分；每 +1% ≈ +8.3 分
  − 40 × clamp( (maxDD     − 0.05) / 0.15 , 0 , 1 )      // 回撤 ≤5% 不罚；≥20% 罚满 40
  − 15 × clamp( (costRatio − 0.002) / 0.010 , 0 , 1 )    // 成本 ≤0.2% 不罚；≥1.2% 罚满 15
S = clamp(S, 0, 100)
// 黄档（NAV < ¥50,000）时：成本罚分 ×0.5，见「恢复路径」
```

| 评级 | 门槛 | 大致对应 | 老周的说法 | 下一步怎么走 |
|------|------|---------|-----------|------------|
| **A 优** | `S ≥ 80` | 无罚分时 `rar ≥ +3.6%` | 「这一章你走得很稳。」 | **进阶加演节拍**（+3–5 分钟）：该章概念的**真实用法延伸**（如第三章带你真的去看一次指数成分股；第五章带你在复盘里算一次汇兑对持仓的真实影响），并解锁该章 1–2 条**词典进阶条目**。**纯内容奖励：不发钱、不加成、不改市场。** |
| **B 良** | `60 ≤ S < 80` | `rar ≈ +1.2% ~ +3.6%` | 「这一章走得不错。」 | 常规推进。 |
| **C 中** | `40 ≤ S < 60` | `rar ≈ −1.2% ~ +1.2%` | 「这一章走完了。」 | 常规推进。 |
| **D 需补** | `S < 40` | `rar < 约 −1.2%`；或收益平平但回撤/成本罚分很重 | 「这一章我们再摆一次。」 | **补救节拍**（+3–5 分钟，**必过**）：老周带你把「钱是怎么少的」逐层拆开（标的 × 事件 × 操作 × 费用），并在节拍末尾给出「一键补足本金」。**完成后照常确认、照常推进，不扣任何东西。** |

> **文案纪律（承接 D-34）**：章末结算面板与评级字样中**禁止出现「失败 / 不及格 / 差 / 淘汰 / 降级 / 扣分」**。D 级一律写作「**本章需要再摆一次**」，沿用 v2.0 已定的「我们再摆一次」语气。

**「跑赢市场」这一行（运气必须可见）**
章末结算面板**固定展示一行「本章大盘同期涨跌（对照，不计分）」**。若玩家 `rar > 大盘同期涨跌`，面板额外给出一行明确肯定：「**你这一章跑赢了市场。**」并且当本章评级为 D 时，**补救节拍的内容随之切换**——从「你哪里做错了」改为「这一章市场很差，你做对的地方是没被吓到」。
> **为什么必须有这一行**：本作行情由**章节定向事件**驱动，章节之间的市场基调天生不同（第三章偏暖：`M02`+`I02`；第六章偏冷：`B01`+`M01`）。若不让「运气」可见，评级就会把运气误记成能力，违反 `game-fairness.md` 的难度曲线公平与「不藏机制」要求。这一行不计分，只负责**说真话**。
> **口径（实现者照此，不得自创）**：**本章大盘同期涨跌** = 章内每个交易日取 **A 股 7 只标的当日收盘涨跌幅的等权算术平均**，再把章内所有交易日的该均值**复利累乘**成一个章内总涨跌幅。它只用于对照展示与「是否跑赢」的判定，**永不进入 `S` 的计算**。

**评级不做什么（反正反馈的五把锁，缺一不可）**
用户批准「进度与盈亏相关联」时，同时批准了本节对**经典正反馈死循环**（赢 → 更有钱 → 更容易 → 更赢；输 → 更穷 → 更难 → 更输）的**显式防御**。这五把锁是本设计的核心，不是补丁：

| 锁 | 内容 | 依据 |
|----|------|------|
| **L1 同章相对口径** | `rar` 与 `maxDD` 都相对**本章自己的起点净值**，绝不相对初始 ¥100,000。一个从 ¥60,000 出发的玩家与一个从 ¥100,000 出发的玩家，面对**同一条评分曲线、同一个世界**。**这是最重要的一条：它把「越亏越难」切断在源头，也让翻盘在结构上永远可能。** | `feedback-loops.md`「Pair with negative feedback」——把累积劣势在每章重置为相对量 |
| **L2 评级不改变市场** | 评级**绝不**影响行情生成、事件抽取、事件幅度、费率、涨跌停、撮合、最小单位与解锁条件。世界对所有玩家、所有评级完全相同。 | `game-fairness.md`「不得有隐藏惩罚/隐藏机制」；`information-design.md` 完美信息 |
| **L3 评级不给资源** | A 级**不发钱、不发折扣、不发仓位加成、不发费率优惠**。奖励只有**内容与见证**：加演节拍 + 词典进阶条目 + 老周的评语 + 结业证书上的一行字。**成绩与资源彻底解耦 = 财富雪球在结构上无法启动。** | `feedback-loops.md`「Cosmetic rewards」「Limit magnitude」 |
| **L4 弱者得帮助** | D 级触发的是**补救节拍（帮助）**，不是惩罚；补救节拍**必过**（答错只重讲），且末尾直接提供补足本金。黄档还有成本罚分减半。 | `feedback-loops.md` 核心原则「Reward, not punish」；「Resource compensation」 |
| **L5 上限与压缩** | `S` 被 clamp 在 `[0,100]`；收益项在约 ±6% 之外饱和；回撤与成本罚分各有硬上限（40 / 15）。**一次灾难不会拖低后面七章；一次暴赚也换不来任何实物优势。** | `feedback-loops.md`「Diminishing returns, set caps」 |

**结构性补充：财富在本作里不产生任何机械优势**
本作**没有**保证金、**没有**融资、费率不随资金量变化、**没有**按净值解锁的杠杆，且 `rar` 是一个**百分比**——因此「更有钱」不会让下一章更容易。唯一残余的资金相关差异是**最小交易单位的门槛**（钱少则买不起高价标的，且固定佣金的占比更高：¥5 佣金在 ¥620 的买单上是 0.8%，在 ¥620,000 的买单上只有 0.001%）。本作用三条措施对冲：
1. `costRatio` 的分母是**成交金额**而非本金，使费用惩罚只反映习惯；
2. **黄档成本罚分 ×0.5**；
3. **老周在补救节拍里明说这件事**：「你的费用占比比大资金高，这不是你的错，是固定费用的性质——所以先把仓位做小、次数做少。」
> **设计取向**：小资金的结构性劣势是**真实存在**的市场事实，本作不假装它不存在，而是**把它变成教学点**，同时用罚分减半让它不至于变成惩罚。

**章内亏钱时能不能离开这一章？（逐章无歧义回答）**
- **可以。任何一章都不存在失败态，任何余额都能离开这一章。**
- **章内亏钱（NAV 跌破红线 ¥10,000，章内任意时刻）** → **暂停节拍推进**，插入补救节拍（其中包含「一键补足本金」入口），完成后**回到被打断的那个节拍**，继续往下走。
- **章末评级为 D** → 先完成补救节拍，才能点章末确认；补救节拍必过，所以**永远离得开**。
- **同一章最多出现一次补救节拍**：若章内已因红线触发过，章末 D 级**不再重复触发**，只显示评级与一行点评（避免连续两段「拆账」造成疲劳）。反向也成立。
- **出场条件在任何一章都不包含**「盈利」「净值达到 X」「持有某标的」。**唯一与钱有关的出口条件是「若评级为 D，完成一次补救节拍」**，它必过、不扣任何东西、不影响任何解锁。逐章细则见 `## 主线章节地图` 每章的「章末评级」与「出场条件」两行。

**恢复路径（三级资金阶梯，触发条件明确）**

| 档 | 触发条件 | 玩家看到 | 可做的事 |
|----|---------|---------|---------|
| **绿** | `NAV ≥ ¥50,000` | 无提示 | 正常 |
| **黄** | `¥10,000 ≤ NAV < ¥50,000` | 章目标卡常驻一行「你的本金只剩 ¥X。随时可以补足。」+ 一个「补足本金」按钮；老周每章最多非侵入提示一次 | 一键补足；**成本罚分 ×0.5** |
| **红** | `NAV < ¥10,000`（沿用既有风险警示线） | 风险警示 + **强制补救节拍**（章内最多一次） | 补救节拍末尾「一键补足本金」；成本罚分 ×0.5 |

- **「一键补足本金」**：`cash += (¥100,000 − NAV)`，补足后 `NAV = ¥100,000`；**持仓保留、净值曲线保留、章节进度 / 解锁 / 词典 / 老周关系全部保留**。**不限次数、不惩罚、不需要任何理由。**
- **「重置账户」**（既有规则，v1.0 起就有）：清空持仓 + `cash = ¥100,000`；其余同上。
- 老周对这两件事的态度是**正常化**的：「这是训练场，不是成绩单。钱不够了就说一声。」
- **No-Dead-End 承诺在 v2.1 依然完整**：任何余额、任何评级、任何亏损路径下，玩家都能在**两步之内**（补救节拍 → 补足本金）回到「可继续学习」的状态，且已学内容永不丢失。

**与结业证书的关系（盈亏如何进入结局）**
证书上有**「结业评定」**三档，**三档全部都是毕业**（都解锁全部七类品种与自由模式、都拿到结业证书）：

| 评定 | 判定条件 |
|------|---------|
| **优秀** | 实际记录的章末评级中 `A ≥ 4` 次（绝对次数，全剧共 6 次评级），**且**全程调整后累计收益 `> 0` |
| **良好** | `A + B ≥ 4` 次 |
| **结业** | 其余**全部**情形——**包括亏掉大部分本金，包括反复补足本金** |

- **全程调整后累计收益** = `(NAV_final − Σ全部外来入金 − ¥100,000) / ¥100,000`。剔除外来入金是诚实的口径，也让「我亏过、我又补回来、我最后是正的」成为玩家能看懂的**真实结论**。
- 三档的差别**只在**：① 证书上的一行字；② 尾声 E.2 里老周念出的那段话；③ 评级的完整记录表。**三档都不改变任何解锁、任何内容、任何后续可玩性。**
- 因此 **D-1「胜利 = 理解而非盈利」依然成立**：能不能毕业只看理解确认。v2.1 新增的是**第二层**——**成绩（standing）来自盈亏**。**理解决定你能走多远，成绩决定你走得怎么样、以及你被记成什么样子。**

**这个设计明确做的取舍，以及它的风险（必须写下来，不许模糊）**
- **取舍**：我们放弃了 v2.0「账户与进度彻底解耦」的纯粹心理安全，换取用户要求的「盈亏真的算数」。为了让这笔交换不变质，我们把盈亏的影响力**严格限制在「怎么走」与「怎么被记住」两个维度**，并把它**排除在「能不能走」与「市场难不难」之外**。
- **风险 1 · 评级把运气记成能力**：行情由章节定向事件驱动，章节之间基调不同（第三章偏暖、第六章偏冷）。已用「跑赢市场」对照行 + D 级补救节拍内容切换对冲。**若实测仍有玩家因单章行情被判 D 而感到不公，第一顺位调整手段是放宽收益项斜率（`833 → 600`），而不是降低 D 的门槛。**
- **风险 2 · 补救节拍变成「作业感」**：它是「多讲一遍」，不是「补考」。已用「必过 + 文案禁用失败字样 + 每章最多一次」三条约束压制。**若实测玩家把它读成惩罚，第一顺位调整手段是把它从出口条件降为章末的「可选加演」——但那样「盈亏真的算数」也会随之减弱，需用户重新拍板。**
- **风险 3 · 补足本金削弱成绩感**：补足本金随时可用，理论上玩家可以「亏了就补」。已用「外来入金从 `rar` 与累计收益中剔除」对冲——**补钱不改善任何评级与评定，只恢复可操作性。这是本设计最关键的一条口径，实现者不得简化掉。**
- **风险 4 · 六次评级对轻度玩家形成「被考核」压力**：只统计章内节拍期间的交易，且第一章与第四章不打分，已尽量压缩被评分的窗口。**若实测压力感过强，可进一步缩减为「只统计有硬性交易的章节」。**

### 进度、失败与结局

**进度规则（v2.1）**：
- **能否进入下一章 = 章节确认**（章末那道 10 秒选择题 + 完成该章的必做互动）。**这一层与账户余额完全无关。**
- **怎么进入下一章 = 章末评级**（R5）。A 级追加**进阶加演节拍**；B/C 级常规推进；D 级先完成**一次必过的补救节拍**。评级**不影响市场、不影响解锁、不发资源**（反正反馈锁 L2/L3）。
- 「理解确认」答错**只循环讲解，不阻断、不扣分、不记录失败**（no dead-end 的线性版本）。
- 已解锁的品种、词典条目、章节确认、老周的关系推进、净值曲线历史，**永不丢失**（即使补足本金或重置账户）。

**失败规则（心理安全规则全部保留并强化）**：
- **无 Game Over、无破产判定、无失败画面**（v1.0 规则不变）。
- **章内失败的新语义**：如果玩家某个节拍没做出来（比如产品对比选错了），老周**换一个说法重讲一遍**，节拍重来。文案必须写成「我们再摆一次」，而不是「重试」「你答错了」。**没有「重玩关卡」，只有「再讲一次」。**
- **亏损的新语义（v2.1）**：亏损不再「完全不影响你」——它会在章末给你一个 D，并让你多听一遍讲解。但它**不夺走任何东西**：不掉钱、不掉进度、不掉解锁、不掉老周的态度。**失败在 v2.1 里变成一个多出来的讲解时间，而不是一次扣减。**
- 拒单、亏损、触发警示线，全部仍是教学事件。

**风险警示线（保留，语义与 v2.0 一致）**：当 `NAV < ¥100,000 × 10% = ¥10,000`（或现金近 0 且重仓套牢）时：
1. 触发**风险警示**，游戏继续。
2. **暂停章内节拍推进**，插入一个「补救节拍」——老周带玩家把「钱是怎么少的」拆出来看，给出补救建议与「一键补足本金」，然后把玩家送回主线（回到被打断的那个节拍）。
3. 警示**不改变章节进度、不改变已解锁内容**，同一章最多触发一次。

**「通关」的定义（v2.1）**：
> 走完八章 + 每章的理解确认 + 尾声。**任何余额、任何评级都能通关。** 一个亏了 ¥30,000 但走完全程、能讲清每一类品种的玩家，和一个赚了 ¥30,000 的玩家，**拿到的是同一张结业证书**；区别只在证书上那行「结业评定」（优秀 / 良好 / 结业）与 E.2 里老周念出的那段话。**这是本作对「盈亏算数」与「无死局」两个要求的最终调和。**

**玩家带走的四样东西**：
1. **操作能力**：七类品种在真实券商 App 里怎么下单、各自有什么坑。
2. **一张判断清单**：分散 / 仓位 / 成本 / 期限 / 「我为什么买」——这五问在游戏里被反复用到，玩家会记住。
3. **一份自己的记录（v2.1 加重）**：全程净值曲线 + **六次章末评级记录** + 可回看的复盘报告 + 全部 30 条以上的词典条目（毕业时解锁完整导出/回看）。**这份记录里既有你赚的，也有你亏的——它是玩家自己的弧线，不再是别人的故事。**
4. **老周的那句话**（尾声他离开前说的最后一句，也是全剧的题眼）。**v2.1 说明**：这句话不再是某个秘密揭晓的落点，而是一个**透明的老师对学生的最后一句交代**——它的重量全部来自「你刚刚亲眼看完了自己走过的那八章」。

**品种分布的教学理由**：A 股（1–2 章）是中国小白日常接触最多、规则中等、最适合作起点的品种 → ETF + 基金（3 章）是「不猜个股」的最常用解法，先建立稳健观念 → 第 4 章（机构）不新增品种，用一整章把「交易所 / 券商 / 银行 / 监管」放进生态里，是节奏上的呼吸章，也兑现 goal 里明确要求的机构知识 → 港股（5 章）引入汇率与无涨跌停，难度 +1 → 美股（6 章）再加时区与碎股 → 加密（7 章）是风险教育的高潮，必须后置 → 期权（8 章）最复杂最危险，最后且带理解门槛。此顺序与原 GDD 的 L0–L5 解锁阶梯完全一致，只是把「解锁」绑定到了章而不是绑定到门槛检查。

**事件的分配原则**：20 件事件的 `market` 全部为 `A_SHARE`（v1 事实，不修改），因此事件卡机制在 v1 承担 A 股章的教学情境。下表为每章**定向使用**的事件（用于保证该章需要的教学情境一定出现），其余事件在章内「平淡日」与自由交易日窗口中自然消耗。**所有事件的 headline / mentorLine 文案一律照录，不得改写。**

> **v1 已知缺口（需 report，不在本版改）**：港股 / 美股 / 加密 / 期权四章在 v1 **没有专属新闻事件**（事件池 20 件全为 A 股）。这四章在 v1 以「行情引擎的自然波动 + 叙述性情境」承载，通用宏观事件（M01/M02/M03/P01，`targets=["ALL"]`）只影响 A 股标的，可作为旁证但不能作为这四章的主事件。**建议 v2 为 HK / US / CRYPTO 各补一组事件**（新增，不改现有 20 件）。

### 第一章 · 第一笔钱

**生活处境**：你工作第三年，攒下 ¥100,000，一直放在活期里。上周家庭群里，舅舅转发了一条「某股民一天亏掉半年工资」的新闻，妈妈在电话里说「咱家别碰那个」。同一周，同事午饭时说他今年「靠基金挣了一台车」。你想自己先搞明白——不是要赚钱，是想知道那些人在说什么。

**为什么它让人在意**：这是玩家真正的起点处境——**信息不对称带来的焦虑**。一边是恐吓，一边是炫耀，你夹在中间，最理性的事是「先搞懂」。

**节拍序列**：

| 节拍 | 内容 | 玩家亲手做的事 | 教什么 |
|------|------|--------------|--------|
| 1.1 钱躺着 | 银行大厅场景，一张活期存单近景，老周画外音登场 | 点开存单读数字 | `银行`、`通胀侵蚀购买力`、`存款利率` |
| 1.2 开个户 | 券商 App 第一次出现（只露开户面板）；老周露脸解释「券商不是银行」 | 开户 | `券商`、`资金账户`、`存管`（此处先提一句，第四章展开） |
| 1.3 入金 | 数字从 ¥0 跳到 ¥100,000 | 点入金 | `本金`、`可用资金` |
| 1.4 挑一只买得起的 | 自选列表亮起 7 只标的；**默认高亮买得起的最低价款**；新增「1 手约 ¥XXX」列 | 看行情、比较、点选 | `K线`、`最新价`、`涨跌幅`、`自选`、**`最小交易单位（100 股 = 1 手）`** |
| 1.5 第一单 | 下单面板预填，成交必然成功 | 点「买入」 | `委托`、`成交`、`手续费`、`成交价` |
| 1.6 明天再看 | 老周让玩家点「进入下一交易日」 | 推进一天 | `T+1`、`交易日`、`休市` |
| 1.7 卖掉它 | 第二天卖出，第一次看到已实现盈亏 | 卖出 | `未实现 vs 已实现盈亏`、`持仓成本` |
| 1.8 第一次复盘 | 复盘面板首现，拆解这一笔的完整因果 | 读复盘 | `盈亏归因`（复盘的读法） |

**非交易互动**：读一张存单数字并和老周讨论「1.5% 与 2%」（节拍 1.1）；在自选列表里**主动比较**哪只买得起（节拍 1.4，这是全游戏第一次真正的「判断」）。

**概念**：`银行`、`券商`、`通胀侵蚀购买力`、`本金`、`可用资金`、`资金账户`、`K线`、`最新价`、`涨跌幅`、`自选`、`最小交易单位`、`委托`、`成交`、`手续费`、`成交价`、`T+1`、`交易日`、`休市`、`持仓成本`、`未实现盈亏`、`已实现盈亏`、`盈亏归因`。

**解锁品种**：**A 股**（7 只标的全部开放交易）。

**定向事件**：`I04`（银行业净息差企稳，0.15 GOOD）、`C03`（工商银行分红方案创新高，0.20 GOOD）。**两件都指向银行**——玩家刚买入银行股，温和的利好让他第一次体会「我持有的东西因为我读到的那条消息动了」。事件幅度刻意选小（0.15/0.20），第一章不允许剧烈波动。

**章末评级**：**本章不参与评级**——它是「从开场到第一单成交之间零个可能失败的交互」的教学章。**章目标卡上明写「本章不打分」**（公开规则）。玩家在第一章第一次看到账户变化，但那不产生任何评级。

**出场条件**：完成「买入 → 隔日卖出 → 读复盘」闭环；然后一道 10 秒选择题——「你昨天买的那 100 股，今天能不能卖？为什么？」（选项含 `T+1` 与 `涨跌停`，选错只重讲）。**不要求盈利**，也不要求任何特定标的。**本章不设任何与余额相关的出口条件。**

**情绪落点**：安静的踏实。老周的收场台词是这一章的全部目的：「你刚才做的事，和世界上几亿人每天做的事一模一样。区别只在于——你现在知道自己在做什么。」

### 第二章 · 规则会咬人

**生活处境**：第一章之后你觉得自己已经上手了。周三午休，同事在群里喊「快看这个」，你想在那一刻「露一手」——你想买茅台。你挂了单。**被拒了。** 你不知道为什么。你又试了两次。又被拒了。你有点上火：明明是自己的钱，凭什么不让买？

**为什么它让人在意**：这是**挫败 → 解惑**的完整弧线，也是全游戏情绪最有张力的一章。玩家第一次遇到「系统说不」，而这一章的答案会决定他后面七章对市场的态度——是「这破系统有问题」还是「规则在保护我」。

**节拍序列**：

| 节拍 | 内容 | 玩家亲手做的事 | 教什么 |
|------|------|--------------|--------|
| 2.1 我想买茅台 | 玩家自由尝试买贵州茅台（¥1,480 × 100 股 = ¥148,000 > ¥100,000）→ 拒单 #1 资金不足 | 撞一次拒单 | `最小交易单位（100 股 = 1 手）`、`可用资金不足` |
| 2.2 我出高价还不行？ | 玩家挂一个明显高于涨停的价 → 拒单 #2 超涨跌停 | 撞一次拒单 | `涨跌停`（基准 = 上一日收盘价，±10% / ±20%） |
| 2.3 我买了就想卖 | 玩家当天买入后当天卖出 → 拒单 #4 T+1 | 撞一次拒单 | `T+1` 的风控初衷 |
| 2.4 今天是周六 | 玩家推进到周末，下单 → 拒单 #3 休市 | 撞一次拒单 | `交易日历`、`休市` |
| 2.5 老周的四个问题 | 四次拒单后的四条「规则卡」汇总；老周问：「你觉得这几条规则，是在限制你，还是在保护你？」 | 答一道选择题（两个选项都有回馈，不判对错） | 规则的设计意图（`涨跌停`/`T+1`/`休市` 的存在理由） |

| 2.7 同行业一起跌 | 一条行业新闻（白酒消费降级）让两只白酒股同时下跌 | 观察、读事件卡、可选做一次操作 | `板块联动`、`行业景气度`、`事件驱动行情` |

**概念**：`最小交易单位`、`可用资金不足`、`涨跌停`、`涨停价/跌停价`、`T+1`、`T+0`（对比预告）、`交易日历`、`休市`、`限价单`、`市价单`、`撮合`、`滑点`、`最小变动价位`、`板块联动`、`行业景气度`。

**解锁品种**：无新增（A 股深挖）。

**定向事件**：`I01`（白酒行业消费降级，0.40 BAD，影响 600519+000858）、`C01`（茅台季度发货量不及预期，0.30 BAD）、`I05`（地产竣工放缓拖累家电，0.20 BAD）、`C04`（格力空调旺季疲软，0.35 BAD）、`C07`（招商银行零售业务超预期，0.30 GOOD）。
> 设计意图：`I01` + `C01` 让玩家看见「同一行业的公司一起跌」（板块联动），`C04` + `I05` 复现同一机制，`C07` 提供一个反向的正例（同一板块里并非所有公司都一样）。四拒单章同时是**事件机制的教学章**。

**章末评级**：**参与**（全剧首次评级）。入场时老周直接说明规则：「这一章结束的时候，我会看一下你的账户。别紧张——它是用来看你走得怎么样的，不是用来判断你能不能往下走的。」**这就是评级机制的首次教学。**

**出场条件**：成功提交四类**合法**委托（限价买、限价卖、市价买、一张修正后的限价单），且四张规则卡都能在词典里查到。**不要求盈利。** 若章末评级为 **D**，须**先完成一次补救节拍**（必过、+3–5 分钟、末尾提供「一键补足本金」）才能确认本章——**补救节拍同样不要求任何操作成功，答什么都推进**。理解确认题：「你出价 ¥20 想买一只昨天收 ¥18 的股票，今天涨停价是 ¥19.80。为什么会被拒？」（答错只重讲）。

**情绪落点**：**「被拒绝不是我做错了，是规则在替我说不。」** 老周的一句台词要在这里落地：「你想买茅台买不到，不是因为你穷，是因为它一手就要 14 万——这条规则拦住的不是你的钱，是你的冲动。」

### 第三章 · 一篮子里的一颗蛋

**生活处境**：第二章之后你学会了规则，但你陷入新的焦虑：**到底该买哪一只？** 你在自选列表里翻来翻去，每一只都能找出理由，也都能找出理由不买。同事在群里说「我全仓押了一只，一个月翻倍」——你既羡慕又害怕。老周在咖啡馆坐下，推给你一张纸：「先别选公司。先选方法。」

**为什么它让人在意**：这是**从「猜」到「配」的认知跃迁**。小白的所有痛苦几乎都来自「我必须猜对一只股票」这个假设；这一章要拆掉的正是这个假设。

**章末评级**：**参与**。这一章是评级机制「教学性」最强的一章——玩家在前两章刚学会规则与分散，这一章的市场基调偏暖（`M02` + `I02`），**「把钱放进去、并且分散地放进去」会真实地反映在评级上**。老周会在章末明说：「你这一章赚到的钱，主要来自你**没有押一只股票**。」

**情绪落点**：**「原来不用猜对一只股票，也能参与。我可以不急。」** 这一章要卸掉玩家的赌性焦虑，让他第一次感到「有一条更慢但更稳的路」。

### 第四章 · 隔壁的三栋楼（机构章）

**生活处境**：你换了工作，新公司在金融街旁边。午休出门，你抬头发现三栋楼：一栋写着「证券」，一栋写着「基金」，一栋写着「交易所」。你在第一章开过户、在第三章买过基金，但你突然发现——你根本不知道这三栋楼里的人在做什么，也不知道你的钱经过了几双手。晚上老周约你吃了顿饭。

**为什么它让人在意**：前四章的所有操作都是「点一下按钮」，玩家开始隐约觉得「这钱动得太容易」。**这一章要给系统以重量**——让玩家看见自己的每一笔交易背后有一个真实的、有分工的生态。它同时兑现 goal 里明确要求的「交易所、银行等相关知识」。

**为什么它是呼吸章**：不新增品种、不新增规则、没有拒单、没有压力。它是节奏上的低谷，为第五章的港币冲击蓄力。

### 第五章 · 港币的账，美元的梦

**生活处境**：你已经能看懂 A 股和 ETF 了。有一天你刷到一条新闻说腾讯出了个好东西，你想买。你打开券商 App，发现**你没有港币**。你去问老周，他只回了三个字：「先换钱。」同一周，你妈打电话来问：「我听说港币跌了，你那钱是不是就少了？」——你答不上来。

**为什么它让人在意**：这是玩家第一次遇到**「我的钱不只有价格风险」**。前四章所有的波动都来自标的本身；这一章第一次引入一个**独立于标的、又会影响你盈亏**的变量。它是全游戏认知难度的一次明确跃升，因此放在机构章（呼吸章）之后。

| 5.7 章末 | 老周问：「如果你的钱会同时被两个东西影响，你能做的是什么？」 | 答（不判对错） | `分散` 与 `风险与收益匹配` 的延伸 |

**非交易互动**：读懂汇率面板；**从复盘里把「股价贡献」与「汇率贡献」分开**（这是全游戏最精巧的一次复盘互动）；回答妈妈的问题。

**概念**：`港股`、`汇率`、`汇率风险`、`汇率折算`、`计价货币`、`每手股数不固定`、`T+0`、`T+2 交收`、`无涨跌停`、`熔断`、`波动率`、`风险与收益匹配`。

**解锁品种**：**港股**（5 只：00700 / 03690 / 01810 / 00388 / 01299，每手股数照原表，不改）。

**定向事件**：`M03`（美联储释放鹰派信号，人民币承压，0.30 BAD，`fxTarget=USD`）——**必须放在本章**。
> 设计意图：`M03` 是 20 件事件池中**唯一带 `fxTarget` 的事件**（其余 MACRO/POLICY 事件不带），因此汇率机制的唯一教学窗口就在这里。事件文案不动。其余章节的事件不受汇率影响，这是 v1 的既定事实，不是缺陷。

**章末评级**：**参与**。这一章是评级机制里**汇率与股价共同作用**的第一次——`M03` 让「股价没跌但你亏了」成为可能。结算面板除了三项输入，还要**把浮动盈亏拆成「股价贡献」与「汇率贡献」两行**（与 5.5 的复盘互动共用同一次拆分）。老周会说：「这一章你的账户里有两个人在写字。」

**出场条件**：完成一笔港股买卖；并在复盘里**选对**「这次 NAV 变化中，哪一部分来自股价、哪一部分来自汇率」（答错只重讲）。**若章末评级为 D，须先完成一次补救节拍（必过）才能确认本章**——本章触发 D 的概率是全剧最高的一章（汇率与无涨跌停双重暴露），因此补救节拍在这一章尤其重要，它的第一句是「汇率这一口，很多人第一年都要被咬一次」。

**情绪落点**：**「同一个公司，在不同的地方卖，命运不一样。」** 世界变大了——玩家的地图从「A 股」扩展到了「全球市场」，但同时也第一次意识到「变量也变多了」。

### 第六章 · 凌晨三点的红与绿

**生活处境**：你开始熬夜。北京时间凌晨一点，A 股早就休市了，但大洋彼岸的屏幕刚亮。你抱着手机坐在客厅，家人路过说了一句「你魔怔了」。你发现美股**一股就能买**，甚至能买 0.5 股——一只你一直觉得「太贵买不起」的公司，现在你买得起了。你在凌晨下了一单，然后去睡了。第二天早上醒来，**你错过了整个过程。**

**为什么它让人在意**：这是全游戏唯一一次**「你不在场的时候市场也在动」**。前五章玩家每一次结算都是自己按的按钮（回合制），这一章要打破这个安全感，让玩家意识到「时间本身也是一种风险」。同时，碎股是小白最直接的「原来我也可以」的瞬间。

**节拍序列**：

| 节拍 | 内容 | 玩家亲手做的事 | 教什么 |
|------|------|--------------|--------|
| 6.1 时差 | 一张北京时间对照表（由代码绘制）：美股 21:30–04:00（夏令）；盘前盘后只作科普 | 设置一个「美股时段」提醒 | `交易时段`、`时差`、`盘前/盘后` |
| 6.2 半股也是股 | 买入 0.5 股一只高价美股 | 下单（碎股） | `碎股`、`1 股起`、`最小变动价位 $0.01` |
| 6.3 零佣金？ | 对比同一笔交易的费用：美股 $0.99 平台费 vs A 股佣金+印花税+过户费 | 逐项点开费用对比 | `零佣金`、`平台费`、`费率结构差异` |
| 6.4 没有涨停板，但有熔断 | 极端波动日（熔断仅作提示，不实现） | 观察 | `无涨跌停`、`熔断` |
| 6.5 你睡着的这一夜 | **玩家下完单后必须推进一天（游戏内表达为「去睡觉」）**，第二天早上醒来看到结果与那晚发生的事件 | 推进 + 读复盘 | 「不在场风险」、`止损` 概念的雏形 |
| 6.6 钱不睡觉 | 老周点评：「你昨天睡得挺好，市场替你做了一晚上的决定。」 | 答一道选择题 | `风险与生活的关系`、`长期持有 vs 择时` |
| 6.7 章末 | 老周收场：**他直接说出这一章的用意**——「这一章我不教你任何技术。我只想让你知道：钱不睡觉，但你得睡。你把这句话记住，比记住任何一个指标都值钱。」 | — | —（**v2.1：直接交代，不埋伏笔**） |

**非交易互动**：设置提醒（一个轻量的「安排生活」动作）；费用结构并排对比；**「睡着后发生了什么」的时间线回放**（由代码绘制的时序图）。

**概念**：`美股`、`碎股`、`零佣金`、`平台费`、`时差`、`交易时段`、`盘前/盘后`、`熔断`、`无涨跌停`、`止盈止损`（雏形）、`长期持有 vs 择时`。

**解锁品种**：**美股**。

**定向事件**：`B01`（突发：某大型机构爆雷，市场短暂恐慌，0.60 BAD，全市场）、`M01`（央行意外加息，0.50 BAD，全市场）。
> 设计意图：`B01` 是全池幅度最大的事件（0.60），配合 §Realism 声明「剧烈但非灾难」。用它承载「你睡着时市场恐慌」这一拍最有戏剧性。**注意**：`B01`/`M01` 的 `targets=["ALL"]` 指 A 股 7 只标的，因此玩家醒来时会看到**A 股也一起绿了**——这恰好构成一个教学点：「恐慌是会传染的，一个市场的事会传到另一个市场。」

**章末评级**：**参与**。这是全剧**最容易拿到 D** 的一章（`B01` 0.60 + `M01` 0.50 都是全市场利空），因此本章的章目标卡在开场就**提前公开提示**：「这一章外面风大。」——把「运气」提前说破，是评级公平性的必要一步。**如果玩家这一章 `rar > 大盘同期涨跌`（即比市场跌得少），无论评级如何，结算面板都会明确写出「你这一章跑赢了市场」**，且补救节拍的内容随之切换为「你做对的地方是没被吓到」。

**出场条件**：完成一笔碎股买入 + 一次「推进一天后读复盘」，并能指出「昨晚的价格变动有多少发生在你的交易时段之外」。**若章末评级为 D，须先完成一次补救节拍（必过）才能确认本章。**

**情绪落点**：**「钱不睡觉，但我得睡。」** 这一章不教技术，教**边界**——投资必须在生活里有个位置，而不是反过来。

### 第七章 · 24 小时的赌桌

**生活处境**：大学同学在群里晒了一张翻倍的截图，配文「这还用上班？」。私聊里他劝你也来：「你的钱放着也是放着。」你手上有 ¥5,000 是真的可以亏掉的闲钱。你打算进去试试。老周听说之后，没有阻止你，只让你做一件事：**先写下你最多能接受亏多少，然后才能下单。**

**为什么它让人在意**：这是风险教育的高潮，也是全游戏唯一一次玩家**主动走向高风险**。前六章的玩家一直是谨慎的、被保护的；这一章给玩家一次真正的「我自己要的」。而老周的做法（**先写下底线再下单**）是整章的设计核心——它不是限制，是把「仓位」这个概念变成一个玩家亲手做出的承诺。

**节拍序列**：

| 节拍 | 内容 | 玩家亲手做的事 | 教什么 |
|------|------|--------------|--------|
| 7.1 全天不休 | 玩家推进到一个**周末**：A 股/港股/美股全休市，但加密行情还在跳 | 观察（强烈对比） | `7×24`、`永不休市` |
| 7.2 先写下你的底线 | 老周要求玩家在界面上填一个数字：「这笔钱你能接受亏掉多少？」（**玩家自选，无正确值**） | **写下自己的底线数字** | `本金安全`、`仓位管理`（雏形） |
| 7.3 波动不一样 | 观察到加密的单日波动幅度远大于 ETF（引擎参数 `scale=±25%` vs ETF `±8%`，且这是 GDD 既有参数，不改） | 观察、比较 | `波动率`、`加密 vs 股票` |
| 7.4 第一次自己买 | 买入一小笔（金额由玩家决定） | 自由下单 | `加密货币`、`手续费 0.1% 双边`、`计价货币 USDT` |

| 7.6 回到那个数字 | **关键互动**：老周把玩家在第 7.2 节写下的数字重新提出来，问「这次波动，有没有超出你写下的数？」 | 答一道选择题（两个答案都推进，但对话不同） | 自我承诺 / `纪律` 的意义 |
| 7.7 章末 | 老周点评：「你同学晒的是赢的那一次。他没晒的是输的那九次。」 | — | `幸存者偏差`（词典新条目） |

**非交易互动**：周末的对比观察；**写下自己的底线数字**（全游戏最重要的一次非交易互动）；回答「有没有超出」。

**概念**：`加密货币`、`7×24`、`无涨跌停`、`本金安全`、`仓位管理`、`集中度风险`、`波动率`、`无中央监管`、`风险与收益匹配`、`幸存者偏差`。

**解锁品种**：**加密货币**。

**定向事件**：`I03`（海外限制加码，半导体设备进口受阻，0.30 BAD）、`C05`（中芯国际先进制程量产突破，0.45 GOOD）、`P03`（新能源补贴退坡，0.25 BAD）。
> 设计意图：加密章需要**事件密度高**才能让玩家感到「这里什么都会发生」。这三件 A 股事件在这一章的叙事作用是**旁证**——玩家同时持有多种资产时，会发现「A 股在动、加密也在动，它们并不总是一起动」。这是 v1 事件池限制下的合理用法，不可改写事件文案。

**章末评级**：**参与**。这一章有一处刻意的设计：玩家在 7.2 亲手写下的那个数字，在 7.6 被重新提出来。**章末结算面板会把「你写下的数字」与「你这一章实际的最大回撤」并排放**——这是全剧唯一一次让玩家亲手写的承诺与真实数字对撞。老周不加评语，只把两个数字摆在一起。
> **注意**：7.2 的底线数字**不进入评级公式**（玩家可能写一个很大的数，也可能写一个很小的数，两种都不该被机械奖惩）。它只出现在结算面板的对照行里，作为**自我承诺的可见化**。

**出场条件**：完成一笔加密交易 + 在第 7.6 节回答「这次波动是否超出你写下的数」。**若章末评级为 D，须先完成一次补救节拍（必过）才能确认本章。**

**情绪落点**：**「刺激是真的，但我知道我为什么只买了这么多。」** 这一章不教玩家远离加密，教玩家**带着自己的底线靠近任何东西**。

### 第八章 · 一张会过期的合约

**生活处境**：你已经能看懂前六类了。第二次约在咖啡馆，老周第一次没有带笔记本。他说：「最后一样东西。我想让你先害怕它，再理解它。」他推过来一张纸，上面写着一个日期。

**为什么它让人在意**：这是全游戏最难的一章，也是唯一一次**玩家被作者明确邀请去体验一次「归零」**。玩家已经经历过亏损、汇率、睡眠风险，但他还没见过**东西凭空消失**。时间价值衰减是小白最难理解、也最危险的概念；只有让他亲眼看着一张合约慢慢变成零，他才会真的记住。

**节拍序列**：

| 节拍 | 内容 | 玩家亲手做的事 | 教什么 |
|------|------|--------------|--------|
| 8.1 一张会过期的东西 | 期权链第一次出现：3 个到期序列 × 5 档行权价 × CALL/PUT，标注剩余天数 D | 观察期权链，找出「平值」那一档 | `期权`、`行权价`、`到期日`、`看涨/看跌` |
| 8.2 用 X 元控制 Y 元 | 下单前显示「用 X 元权利金，控制 Y 元名义价值」与杠杆倍数 | 读懂杠杆展示 | `杠杆`、`名义价值`、`权利金` |
| 8.3 标的没动，钱在掉 | 买入 1 张**虚值**期权，连续推进数个交易日，标的几乎没动，权利金却一天天缩水 | **观察时间价值衰减** | `时间价值衰减`、`内在价值 vs 时间价值` |
| 8.4 它归零了 | 让这张合约走到 D=0 且虚值 → 作废，权利金全部损失 | **经历一次完整归零** | `到期归零`、`买方风险有限（最多亏权利金）` |
| 8.5 如果当时你买了 10 张 | 老周问：「如果你第 8.3 天买的是 10 张，现在是什么感觉？」 | 答一道选择题 | `杠杆` 的双向性 |
| 8.6 实值的那一刻 | 再买 1 张**实值**期权并持有到到期，看到现金行权 | 买入 + 推进到到期 | `实值/虚值/平值`、`现金行权` |
| 8.7 期权理解确认 | 一道**小考**（原 GDD 的 L5 门槛保留）：确认杠杆与时间衰减 | 答题（答错只循环讲解，不阻断） | 全部期权概念 |
| 8.8 章末 | 老周说：「这个，我会怕。」——**他紧接着就把为什么讲完**：「我见过太多人在这个东西上把十年积蓄交出去。我说怕，是因为我知道它有多快。你现在也知道它有多快了。」 | — | —（**v2.1：当场讲完，不留悬念、不构成任何个人往事**） |

**非交易互动**：读期权链并找出平值档；读懂杠杆展示；**让一张合约归零**（设计好的、有保护的体验）；老周的两次提问。

**概念**：`期权`、`看涨期权 CALL`、`看跌期权 PUT`、`行权价`、`到期日`、`权利金`、`内在价值`、`时间价值`、`时间价值衰减`、`平值/实值/虚值`、`杠杆`、`名义价值`、`到期归零`、`现金行权`、`买方风险有限 / 卖方风险无限`。

**解锁品种**：**期权**（仅买方；卖方维持关闭，见 D-14）。

**定向事件**：`C02`（宁德时代拿下大单，0.50 GOOD）、`C08`（茅台提价落地，0.40 GOOD）、`P01`（证监会利好政策、下调印花税预期，0.40 GOOD）。
> 设计意图：期权章需要**标的会大幅移动的事件**才能让权利金有戏剧性变化（尤其是让 8.6 的实值期权真的变成实值）。三件都是大事件（≥0.40），符合「越到后期波动越剧烈」的整体难度曲线。

**章末评级**：**参与**（全剧末次评级）。这一章的评级有一处特殊处理：**8.4「让一张合约归零」的权利金损失是本章评级的一部分**，玩家在这里亏的钱会真实地压低本章的 `rar`——这是刻意的，因为这一章的设计目的就是让「我庆幸自己只买了 1 张」这句话被**自己的账户**印证。但正因如此，本章的补救节拍有一句专门的台词：「你不是做错了。你是花了一笔很小的钱，买到了别人要花很多年才肯相信的一件事。」

**出场条件**：完成「一张虚值期权归零」+「一张实值期权现金行权」+ 通过期权理解小考（答错只重讲）。**若章末评级为 D，须先完成一次补救节拍（必过）才能确认本章。**

**情绪落点**：**「我第一次庆幸自己只买了 1 张。」** 不是恐惧，是**敬畏**——玩家离开这一章时对杠杆的态度应该是「我知道它是什么，所以我不会随便用它」。

### 尾声 · 毕业

**生活处境**：你走完了这一整条路。你在咖啡馆等老周，他来得比平时晚。他带来了一个信封。

**节拍序列**：

| E.1 结业 | 结业证书场景（原 `scene_graduation` 美术需求保留）；展示**结业评定三档之一（优秀 / 良好 / 结业，三档都是毕业）**、全程净值曲线、**六次章末评级记录表**、以及整体复盘（真实盈亏，不做美化） | 读完整报告 |

> **v2.1：叙事重量的去向（回应「导师不要隐藏」）**：原 E.2 是「老周的故事」——一次隐藏层揭晓，承担全剧的情感落点。它被移除后，这份重量**整体转移到玩家自己的弧线上**，具体落在三处：
> 1. **E.2 的对照屏**：把「什么都不做的自己」（活期 1.5%）与「真实的自己」（期末净值）并排。**这是玩家全剧唯一一次看见自己的变化有数字**，而且这个数字是他自己一步步走出来的，不是别人讲的故事。它比任何反转都更不可替代——因为反转只有一次，而这笔账只有他有。

**「通关」的判定（v2.1）**：走完 E.1–E.3 + 八章理解确认。**任何余额、任何评级都能走到这里。** 结业评定只改变证书上的一行字与 E.2 里老周念出的那段话的措辞，**不改变任何解锁、任何内容、任何后续可玩性**。

### 章节地图的实现约束（给实现者）

1. **章的顺序是刚性的，章内的操作是软性的**。可以用一个线性章节列表推进；但章内的任何一步都不允许用「禁用按钮 / 强制高亮 / 遮罩」限制玩家的操作（除第一章开场的预填与第二章的四次必撞拒单）。
2. **第一单必须成功**。第一章从开场到节拍 1.5 之间存在零个可能失败的交互。第二章之前不得出现拒单。
3. **两次拒单的教学是刻意的**：第二章的四次拒单必须是**玩家主动触发的**（不是系统弹出来告诉他「这条规则会拒单」）。玩家必须自己撞上去。
4. **期权章的归零也必须是玩家主动的**：8.3–8.4 必须由玩家自己推进到到期，不得自动跳过。
5. **每章进场前的状态**：章节开场时自动保证账户处于「可自由操作」状态（无未成交挂单卡住、无 T+1 锁定影响该章的第一个操作）。这是为了不让上一章的残留状态污染本章的教学瞬间。
6. **事件定向 vs 自然消耗**：表中列出的定向事件必须在该章内被抽到；其余事件按现有 `EventDeck` 规则自然消耗（同一轮内不重复，池空重新洗牌）。定向事件的抽取不得改变现有抽签机制的可测性（见 plan.md 的 `devSetEvent` 钩子）。
7. **每一个非交易互动都必须在 UI 上完成**（读单子、产品对比、配对、写数字、答题），不得写成纯文本段落让玩家「读过去」。
8. **章末评级的实现在章边界处完成，不得侵入市场层（v2.1）**。评级只读三个量（章内 NAV 序列、章内累计交易费用与成交金额、章内外来入金总额），**只写两个输出**（本章评级 A/B/C/D、结算面板数据）。**评级结果不得被任何行情、事件、费用、撮合、解锁逻辑读取**——这是反正反馈锁 L2/L3 的实现级保证，任何反向依赖都视为违规。
9. **评级的输入窗口与章边界严格对齐（v2.1）**：评级窗口从「本章第一个节拍开始」到「本章最后一个节拍结束」。**自由交易日窗口、纯自由模式、以及章与章之间的任何时间，都不进入任何一次评级的统计**。
10. **外来入金必须从评级口径中剔除（v2.1）**：`rar` 与结业评定的累计收益都必须减去外来入金；「补足本金」与「重置账户」都算外来入金。**这是本设计最容易被实现者简化掉、也最不能简化的一条**——简化它会立刻制造「亏了就补、补了不扣」的刷分漏洞，并同时毁掉「盈亏算数」与「心理安全」两个目标。
11. **评级公式与阈值必须对玩家可见（v2.1）**：章末结算面板逐项展开三项输入的计算过程、分数、档次，并在设置里提供完整公式的查询入口。**不得用「综合评分」掩盖算法**（`game-fairness.md`：不得有隐藏机制）。
12. **补救节拍在每一章只能被触发一次（v2.1）**：红线（章内）与 D 级（章末）共用同一次配额，取先触发者。实现时需在章节状态里保存一个「本章补救已用」标记，跨边界重置。
13. **导师不得携带任何隐藏层（v2.1）**：不得实现「碎片收集」「咖啡杯状态」「身份揭示」「延迟台词」等任何性质的伏笔机制。老周的台词在任一章都必须是**当章即可理解**的。

### Account & Settlement Model

#### 账户状态（实现者须精确实现以下字段与算术）

```
account = {
  cash: float,            // 可用资金（本币 CNY）
  frozenCash: float,      // 冻结资金（已挂未成交限价单占用）
  positions: [            // 持仓列表
    {
      instrumentId: str,
      market: 'A_SHARE'|'ETF'|'FUND'|'HK'|'US'|'CRYPTO'|'OPTION',
      side: 'LONG',       // 仅多头；小白不教做空（见决策日志）
      qty: float,         // 持仓数量（股 / 份 / 张）
      avgCost: float,     // 持仓成本价（不含费，见下方说明）
      currency: 'CNY'|'HKD'|'USD'|'USDT',
    }
  ],
  realizedPnL: float,     // 累计已实现盈亏（统一折算为 CNY）
}
// 以下为派生值，每刻计算，不必持久化：
//   marketValue_i = lastPrice_i * qty_i * fx(currency_i -> CNY)
//   unrealizedPnL = Σ (lastPrice_i*qty_i*fx - avgCost_i*qty_i*fx)
//   NAV = cash + frozenCash + Σ marketValue_i
```

#### 初始本金与重置（已实现规则）

- **初始模拟本金（固定）**：`¥100,000 CNY`。玩家以「开户入金」形式获得，**不**要求自选金额或选择档位——固定数额降低决策负担（flow / chunking，避免入门即陷于「该拿多少钱玩」的分析瘫痪），同时让「本金」本身成为新手任务 2 的首个教学点。
- **本金语义**：所有 NAV、收益、风险警示线均以这 ¥100,000 为基准；不同标的市值经 `fx` 折算后计入同一 CNY 本金池。
- **No-Dead-End 重置**：触发「重置账户」时，`cash` 恢复为 `¥100,000`、`frozenCash` 清零、`positions` 清空；**已学概念、已解锁进度、净值曲线历史全部保留**（仅清空资金与持仓，便于重新练习）。风险警示线不因此改变。

#### 成交算术（实现者照此实现）

- **市值（本币）**：`marketValue_i = lastPrice_i × qty_i × fxRate(currency_i→CNY)`
- **未实现盈亏**：`unrealizedPnL = Σ(lastPrice_i×qty_i×fx − avgCost_i×qty_i×fx)`
- **净资产 NAV**：`NAV = cash + frozenCash + Σ marketValue_i`
- **当日收益（day return）**：`NAV_end_of_day − NAV_start_of_day`

**买入（成交价 P，数量 Q）**：
```
grossCost = P × Q
fee       = computeFee(market, side=BUY, grossCost, qty)
required  = grossCost + fee
// 挂单：冻结 required 到 frozenCash，不立即扣 cash；成交时再扣
cash     -= (grossCost + fee)
// 加仓时更新 avgCost（不含费，费用已走现金）：
newAvg = (oldQty×oldAvg + Q×P) / (oldQty + Q)
qty    += Q
```

**卖出（成交价 P，数量 Q）**：
```
proceeds = P × Q
fee      = computeFee(market, side=SELL, proceeds, qty)
cash    += (proceeds − fee)
realizedPnL += (P − avgCost) × Q − fee      // 本币
qty     -= Q                                 // avgCost 不变
```

> **简化声明（写实 vs 易读）**：`avgCost` 取「不含费」口径，费用在现金侧单独扣除，已在「已实现盈亏」中通过 `− fee` 体现。真实券商常把费用摊入持仓成本，本作为易读性刻意不摊——实现者与玩家均须知此点（见决策日志 D-11）。

#### 每个交易日的结算流程（「进入下一交易日」时执行）

1. **行情推进**：行情引擎为每个标的生成新一日 K 线（open/high/low/close），受当日新闻事件影响。
1.5. **汇率更新**：若当日存在 `fxTarget` 事件，按汇率系统公式更新对应货币对（HKD/USD/USDT→CNY）；无事件则汇率不变。
2. **持仓重估**：更新所有持仓 `marketValue` 与 `unrealizedPnL`（非 CNY 持仓用当日最新汇率折算）。
3. **到期处理**：期权到期结算/行权；基金净值按当日 NAV 更新；休市市场跳过。
4. **解除锁定**：A 股买入次日解除 T+1（当日买的，下一交易日可卖）。
5. **挂单处理**：默认「当日有效」——跨日未成交的限价单自动撤销并释放冻结资金（教学清晰；不实现 GTC）。
6. **费用扣除**：所有成交费用已从 `cash` 扣减（见上）。
7. **净值记录**：写入当日 NAV，供净值曲线与复盘使用。

**公募基金净值（NAV）生成规则（可解释，非黑箱）**：

每只公募基金绑定一个 `trackedInstrumentId`（如沪深300ETF 510300）。每日净值：

```
NAV_t = NAV_{t-1} × (1 + trackedMove_t + fundNoise)
trackedMove_t = 跟踪标的当日 eventMove（见行情公式，不含杂波）   // fundDrift = 0，不另加偏置
fundNoise     = 均匀随机 ∈ [−0.001, +0.001]                      // 跟踪误差，复盘展示为「跟踪误差 ±0.1%」
```

- 玩家能直接看懂「基金净值涨，是因为它跟踪的指数今天涨了；微小偏差是跟踪误差」——满足完美信息。
- **申购成交价** = 下单当日 T 收盘后 NAV（未知价交易）；份额 T+1 交易日确认到账。
- **赎回结算** = 确定性 **T+3 交易日**到账（cash 在 T+3 交易日开始时入账；不再用非确定的 T+2~T+4）。

**涨跌停计算（A股 / ETF 主板）**：

- **基准价** = **上一交易日收盘价（previous close）**。

- 拒单 #2 的区间 `¥X–¥Y` = `跌停价 – 涨停价`，均显示 2 位小数。
- 港股 / 美股 / 加密 / 基金 / 期权**无涨跌停**（港股/美股有熔断，本作仅作提示不实现）。

### 汇率系统 (FX)（已实现：事件透明驱动）

所有非 CNY 持仓经 `fx(currency→CNY)` 折算入 NAV。汇率为**可见、可解释**参数（information-design 完美信息；game-fairness 不藏暗随机）。

**初始汇率（固定教学值）**：

| 货币对 | 初始汇率（1 单位外币 = X CNY） | 说明 |
|--------|-------------------------------|------|
| HKD→CNY | `0.9200` | 港币折算 |
| USD→CNY | `7.2000` | 美元折算 |
| USDT→CNY | `7.2000` | 稳定币：1 USDT 锚定 1 USD，故等同 USD→CNY |

**每日汇率变动公式（仅事件驱动，无隐藏漂移）**：

```
rate_today  = rate_prev × (1 + fxEventImpact + fxNoise)
fxEventImpact = sentiment × magnitude × FX_SCALE      // FX_SCALE = 0.03（单事件最大 ±3%）
fxNoise       = 均匀随机 ∈ [−0.002, +0.002]           // 极小杂波，复盘展示为「汇率杂波」
```

- **哪些事件移动汇率**：仅 `type ∈ {MACRO, POLICY}` 且带 `fxTarget`（被影响货币）字段的事件。例：「美联储加息」→ `fxTarget=USD` `sentiment=BAD`（美元升值 → USD→CNY 上行）；「香港经济数据走弱」→ `fxTarget=HKD` `sentiment=BAD`。纯 `COMPANY/INDUSTRY/BLACK_SWAN` 个股事件**不**动汇率。
- **可见性**：事件卡同时显示「受影响的汇率：USD→CNY 7.2000 → 7.4160（事件驱动 +3.0%）」，玩家先看见原因再看数值。
- **精度**：汇率展示与存储保留 4 位小数；折算 NAV 时按 4 位计算。

### 交易日历 (Trading Calendar)（已实现：简化但确定）

一个「交易日」= 推进 1 个**自然日**的行情（回合制整日模型，见订单章关于交易时段的说明）。日历**确定性**生成，便于初学者理解：

- **CN / HK / A股 / ETF / 基金 / 期权**：周一至周五为交易日；**周六、周日休市**（不推进该市场行情，玩家在该日对该市场下单会被拒「休市」）。
- **美股**：同周一至周五交易、周末休市；另有固定美股节假日 `H_US = {1/1, 7/4, 11月第4个周四(感恩节), 12/25}` 休市。
- **港股**：同 CN 节假日 `H_CN = {1/1, 2/10–2/12(春节), 5/1, 10/1–10/3(国庆)}` 休市。
- **加密货币**：**7×24 永不休市**（任何自然日都推进）。
- **重合休市**：周末时 CN/HK/US 三大市场**同一 turn 全部休市**；个别节假日仅部分市场关闭（如 7/4 仅美股休）。
- **实现约束**：每次「进入下一交易日」把 in-game 日历 +1 天；若该日对某市场为休市，则该市场 `close` 不变、挂单拒「休市」、已有持仓仍按上一日市值计（不重估）。交易日序号连续累加，不跳过计数。

### Order Types & Matching

**订单类型**：
- **限价单 (limit)**：指定价格。买入限价在「最新价 ≤ 限价」时成交；卖出限价在「最新价 ≥ 限价」时成交；否则挂起并冻结资金（限价买）或锁定持仓（限价卖）。
- **市价单 (market)**：以当前对手价立即成交，可能含滑点。

**成交价推导（实现者照此）**：
- 市价买入：`fillPrice = lastPrice × (1 + slippagePct)`，`slippagePct` 默认 `0.001`（0.1%，教学用）；市价卖出：`fillPrice = lastPrice × (1 − slippagePct)`。
- 限价成交：`fillPrice = min(限价, 对手价)` 取优（价格改善），即成交价不差于限价；若未触发条件则挂起。
- **部分成交**：本作默认「全成交或全挂起」，不模拟部分成交（流动性充足模型），以降低初学认知负担（简化声明见 D-10）。进阶场景可后续引入「成交量不足」。

**拒单条件（每条必须给一句玩家可读的中文原因）**：

| # | 拒单条件 | 玩家可见原因（示例文案） |
|---|---------|------------------------|
| 1 | 可用资金不足 | 「可用资金不足，还差 ¥X（含手续费）」 |
| 2 | 委托价超涨跌停（A股/ETF 主板 ±10%，创业板/科创板 ±20%） | 「委托价超出今日涨跌停区间（¥X – ¥Y）」，X=跌停价、Y=涨停价，由上一交易日收盘价计算（见涨跌停规则） |
| 3 | 休市（周末 / 节假日 / 该市场当日关闭；**注：整日模型下不存在「日内非交易时段」可达的拒单**） | 「今天该市场休市，无法下单」 |
| 4 | A 股 T+1 未解禁 | 「A 股实行 T+1，今日买入需下个交易日才能卖出」 |
| 5 | 期权已到期 | 「该合约已到期失效，无法交易」 |
| 6 | 数量不符合该市场最小交易单位 | 按市场给原因：A股/ETF「最小交易单位为 100 股/份（1 手）」；港股「最小交易单位为 N 股（该标的每手股数，见港股清单，如腾讯 100 / 小米 200）」；美股「数量须 ≥1 股，支持碎股（最小 0.001 股）」；加密货币「下单金额须 ≥ ¥100」；基金「申购金额须 ≥ ¥100」；期权「须为整数张（1 张起）」 |
| 7 | 价格精度不符（价格非该市场最小变动价位的整数倍） | 按市场给原因：A股/ETF「价格需为 ¥0.01 的整数倍」；港股「价格需为 HK$0.01 的整数倍」；美股「价格需为 $0.01 的整数倍」；加密货币「价格需为 0.0001 USDT 的整数倍」；基金/期权「价格需为 0.0001 的整数倍」 |
| 8 | 可卖持仓不足 | 「可用持仓不足，无法卖出」 |
| 9 | 基金未知价 | 不拒单——场外基金照常受理，但**成交价以下一交易日净值计**，需提示「净值未知，按收市后净值成交」 |

> 所有拒单都是**安全失败**：触发时导师弹出温和解释 + 关联概念词典，绝不让玩家感到被刁难（psychological safety）。

### Options Subsystem（期权子系统）

期权是七类中最难的教学目标。设计原则：**透明可手算**，玩家必须能「看见价格为什么动」。

#### 确定性定价模型（非 Black-Scholes，刻意简化）

对每个期权合约，给定：标的价 `S`、行权价 `K`、剩余天数 `D`（整数 ≥0）、总天数 `D0`、波动情景因子 `volFactor`（由事件给定，0.5–2.0）。

```
moneyness_m = |S − K| / K                      // 价内/价外相对距离
atmFactor   = clamp(1 − moneyness_m / 0.2, 0, 1)   // 平值最高，偏离 20% 外归零
timeValue   = K × 0.02 × (D / D0) × atmFactor × volFactor   // 线性时间衰减，最易读
intrinsic   = (call ? max(0, S−K) : max(0, K−S))
premiumPerShare = intrinsic + timeValue
premiumTotal     = premiumPerShare × multiplier        // multiplier = 10000（每手份数）
```

- **杠杆可视化**：`名义价值 notional = S × multiplier`；`杠杆 = notional / premiumTotal`。玩家下单前可见「用 X 元权利金，控制 Y 元名义价值」。
- **时间衰减**：每过一个交易日 `D −= 1`，`timeValue` 随 `D/D0` 线性下降（其他不变时）。玩家能直接看到「标的没动，权利金却缩水了」——这就是「时间就是流逝的钱」。

#### 期权链生成（合约清单规则，确定性）

以 50ETF（510050）为唯一标的（与 GDD「50ETF 期权」一致）。链上恒有 **3 个未到期序列**，规则如下：

- **到期序列与生命周期 D0**：近月 / 次月 / 季月，生命周期 `D0 ∈ {30, 60, 90}` 交易日。新合约上市时 `D = D0`（剩余天数从生命周期满值起算）。
- **行权价 K（5 档）**：围绕合约**上市时**标的价格 `S0` 取 `K ∈ {0.8, 0.9, 1.0, 1.1, 1.2} × S0`，再按价位取整：`<¥3` 取 0.05 间隔、`¥3–10` 取 0.1、`>¥10` 取 0.5。每档同时挂 CALL 与 PUT → 每序列 10 张合约。
- **随时间刷新**：每个交易日所有未到期合约 `D −= 1`；当某序列 `D=0` 结算后，立即以**当前** 50ETF 价重新取 5 档 K、新序列 `D0` 重置（近月补新、次月→近月、季月→次月），确保场上始终 3 个序列。
- **D0 初值**：L5 解锁时三个序列分别赋 `D0 = 30 / 60 / 90`，`D` 同值。
- 玩家可见：期权面板列出「到期日(剩余 D 日) × 行权价 × CALL/PUT × 权利金」，并能看 K 与 S 的价内/价外关系。

#### 到期结算与行权（欧式现金交割，刻意简化）

- **到期日（D = 0）结算**：
  - **实值 (intrinsic > 0)**：自动**现金行权**。买方收到 `intrinsic × multiplier` 现金；卖方支付同等金额。
  - **虚值/平值 (intrinsic = 0)**：合约作废，**买方损失全部权利金**（权利金在开仓时已付），卖方保留权利金。
- **买方最大亏损 = 权利金**（核心教学：风险有限）；**卖方风险理论无限**（本作仅教买方，卖方仅作风险提示，不开放交易）。
- 结算后 `realizedPnL`：`买方 = intrinsic×multiplier − premiumPaid`；`卖方 = −(买方)`。

#### 权衡声明（Tradeoff，写实 vs 易读）

为换取「玩家能手算并看见每个驱动因子」，我们**刻意放弃**：Black-Scholes 模型、波动率曲面、美式提前行权、实物交割。改用**欧式现金交割 + 线性时间衰减 + 平值因子**的透明模型。这是明确的教学取舍，实现者与玩家都应知悉（见 D-3）。

### News / Event System（新闻事件系统）

行情由**可解释的事件**驱动——这是本作「信息透明」哲学的核心落地。

**事件结构**：
```
event = {
  id, day, market,
  targets: [instrumentId],        // 受影响标的
  type: 'MACRO'|'COMPANY'|'INDUSTRY'|'POLICY'|'BLACK_SWAN',
  sentiment: 'GOOD'|'BAD'|'NEUTRAL',
  fxTarget: 'HKD'|'USD'|'USDT'|null,   // 仅 MACRO/POLICY 且影响汇率时非空（见汇率系统）
  magnitude: float(0–1),           // 影响强度
  conceptKeys: [str],              // 关联概念词典条目
  headline: str,                  // 新闻卡标题
  mentorLine: str,                // 导师点评文案
}
```

**行情影响（确定性 + 可见杂波；参数已落地）**：

对每个受影响标的，先算「当日净驱动」再生成完整 K 线（OHLC）。所有参数公开、可手算（`sentiment` 在计算中记为 +1 GOOD / −1 BAD / 0 NEUTRAL）：

| 参数 | 含义 | A股/ETF | 港股 | 美股 | 公募基金(NAV) | 加密货币 |
|------|------|---------|------|------|--------------|---------|
| `drift` | 教学用微小长期偏置/日（恒定、可见） | +0.0003 | +0.0002 | +0.0003 | +0.0003（随跟踪标的） | 0 |
| `scale` | 单事件最大冲击幅度（×magnitude） | ±0.08 | ±0.12 | ±0.10 | ±0.06 | ±0.25 |
| `noise` | 可见市场杂波（复盘展示为「市场杂波 ±X%」） | ±0.003 | ±0.004 | ±0.003 | ±0.001 | ±0.015 |
| 基础 wiggle（OHLC 高低波动） | 见下 | 0.005 | 0.008 | 0.006 | 0.003 | 0.020 |

- **收盘价**：`close_today = close_prev × (1 + drift + sentiment×magnitude×scale + noise)`
  - `crypto` 用 `scale=±0.25`，使单事件最大可达 ±25%，**明显比 ETF(±8%) 更剧烈**——直观教学「加密波动远高于股票」。
- **完整 K 线（OHLC）派生**（均四舍五入到该市场最小变动价位）：
  - `eventMove = drift + sentiment×magnitude×scale`（当日净驱动，不含杂波）
  - `open  = close_prev × (1 + 0.5 × eventMove)`（事件冲击的一半体现为开盘跳空）
  - `high  = max(open, close) × (1 + wiggleHigh)`，`low = min(open, close) × (1 − wiggleLow)`
    - `wiggleHigh = wiggleLow = 0.5×|eventMove| + baseWiggle_m`（baseWiggle 见上表）
  - 无事件日：`eventMove≈drift`，价格仅随微小 drift + 可见杂波缓慢移动，K 线收窄——符合「平淡日」直觉。
- 事件在当日结算**前**作为「新闻卡」弹出，玩家先读后看价格反映——**绝不藏信息**（information-design 完美信息；game-fairness 不藏暗随机）。

**每日子时序（回合制下唯一可达的顺序，实现者照此）**：
1. 进入第 N 个交易日：先抽取当日事件（若该日无事件则为空事件日）。
2. 立即据此计算第 N 日 K 线与最新价，并更新行情面板。
3. 弹出第 N 日新闻卡（标题 + 为什么价格会动 + 导师点评）。
4. 玩家在**已经反映该事件的价格**上交易（观察 / 下单 / 观望）。
5. 点击「进入下一交易日」：执行结算（见 Account & Settlement Model 的结算流程），随后进入第 N+1 日，回到步骤 1。

> **为什么玩家不能在价格变动前抢跑**：本作刻意**不提供**「读到好消息后按旧价买入」的窗口。若允许，玩家会在几轮内发现「读新闻 = 无风险套利」，从而建立**错误的心智模型**（现实中没有公开信息套利这种好事）。正确的心智模型是：公开信息**已经**体现在价格里；你的决策是在已知价格上判断「这个价格值不值得买 / 卖」，而不是预测下一跳。

**教学瞬间**：事件卡点击展开 → 显示「为什么这条消息让价格动」+ 关联概念词典链接 + 导师一句点评（如：「这条利空让价格跌，因为公司盈利不及预期，买的人少了」）。黑天鹅事件配专属插画（见美术需求）。

### Learning Systems（学习系统，三件套必备）

#### 1. 概念词典（首版本必须覆盖的概念，按主题分组）

| 品种类型 | `A股` `ETF` `公募基金(场外)` `港股` `美股` `加密货币` `期权` `指数` `蓝筹/成长股` |

> 每个概念条目 = 一句话定义 + 一段通俗解释 + 一个生活化比喻 + 关联概念链接。游戏内随时可检索。
>
> **v2.0 补充条目（因章节教学点而新增，不删除任何原有条目——见 D-36）**：
> - 品种与场所：`场内 vs 场外`、`未知价交易`、`每手股数不固定`、`碎股`
> - 价格与费用：`交易成本`、`买卖价差`、`流动性`、`平台费`、`止盈止损`
> - 风险：`汇率折算`、`熔断`、`盘前/盘后`、`仓位管理`、`纪律`
> - 机构与生态：`存管`、`清算交收（跨市场）`
> - 期权：`实值/虚值/平值`
> - 投资理念：`机会成本`、`幸存者偏差`
>
> **概念与章节的绑定**：每个条目在词典中标注它属于哪一章（只有已学章节的条目会展开全文，未学章节的条目只显示名称与「下一章你会用到它」——这是引导而非限制，玩家仍可随时点开看）。
>
> **「投资理念」层的必要性（回应 goal：用户明确要求学「投资的基本理念与概念」，而非只认品种名称）**：根据 Koster「游戏即低风险学习工具」——若只教工具（ETF/期权是什么）而不教思维（为什么要分散、复利如何滚雪球），玩家学完仍不会「理解」，游戏便停止教学、变得无聊。因此本作把上述理念作为**独立可检索 + 导师在每日复盘/解锁时穿插讲解**的一层：例如导师在玩家首笔盈利后点出「这就是复利雏形」，在重仓单只时引出「分散投资 / 风险与收益匹配」。该层不绑定某一市场，而是贯穿全程，是「毕业」理解确认的一部分。

#### 2. 导师角色（艺术家将据此绘制）

> **v2.0 变化**：老周从「一个对话框」升级为**贯穿全剧的线索人物**。他在线性主线里的完整行为规范、出场时机与弧线见上文 `## 线性主线设计 → 导师在主线里的行为`。本节只保留角色设定与美术相关部分。
> **v2.1 变化**：他的**隐藏层被移除**（用户裁决「导师不要隐藏」）。他全程是一个直接、透明、功能明确的老师——**没有秘密、没有反转、没有延迟揭晓**；他在每一章都会明说「我现在在教你什么、为什么」。

- **身份**：「周老师」（昵称老周），一位资深但已退役的投教导师/老券商，专为小白答疑。**在主线里他是一个你约得到的人**——前四章他在场（银行大厅、咖啡馆、饭桌），第五章起退为「随时可呼出」。
- **性格**：耐心、幽默、不说教、爱用生活化比喻（买菜、买房、存钱）。像邻家长辈，从不制造焦虑。**他从不否定玩家的选择，只点评选择的后果。**
- **何时开口**：① 章开场与章末各一次（写好的台词）；② 玩家首次遇到某概念时；③ 被拒单/亏损/触警示线时先安慰再解释；④ 玩家主动呼叫时。**自由交易日与章内自由操作时绝不主动弹窗**（唯一例外：风险警示线）。可随时静音，不刷屏。
- **如何不唠叨**：用「提问 + 比喻 + 留白」引导玩家自己想；每个概念最多主动讲 2 次；提供可折叠的「导师小贴士」；对话历史随时可回看。**非剧情发言在设置里可整体关闭。**
- **他给视角，不给答案**：玩家问「我该怎么办」，他的回答永远是「我们先把这两件事摆一起看看」。这是刻意的——答案会杀死判断力。
- **视觉（定性与生动，无尺寸/帧数）**：中年男性，细框眼镜，微胖，常穿针织衫或衬衫，笑容温和；身后办公室有绿植与冒着热气的咖啡杯（**v2.1：这只是一间温暖的办公室，咖啡杯不具有任何第二层含义**），背景是模糊的 K 线墙。需一套**表情集**：讲解、欣慰、提醒、偷笑、严肃（讲风险时），以及 **v2.0 新增的两态**：**示弱 / 为难**（第八章「这个，我会怕」——**当场讲完原因，不作悬念**）与**告别 / 释然**（尾声）。角色为 AI 生成位图，**画面内不得含可读文字**（文字全由代码绘制）。
- **他的弧线六段**（牵引 → 松手 → 退后 → 直言 → 敬畏 → 交还）：**他的弧线就是玩家的弧线**。他退场的时机 = 玩家独立的时机。**v2.1：弧线讲的不是秘密，而是他功能的变化——从牵着你的手，到你不需要他的手。**
- **他不藏事（v2.1）**：他每一次出现的目的都是可见的；他讲一个概念时会明说「你现在需要懂这个，因为……」。**不藏动机、不藏身份、不留后手。** 他也会**主动对玩家说明评级机制**：「这一章结束我会看一下你的账户。它是用来看你走得怎么样的，不是用来判断你能不能往下走的。」

### Unlock Progression（解锁进度）

> **v2.0 变化**：门槛的**内容**不变（原来那套「理解程度」判据是对的），但门槛的**载体**从「独立的小测验/任务」改为「章节的理解确认」。解锁不再是玩家在学习之外额外做的一件事，而是走完一章的自然结果。
> **v2.1 明确（呼应 R5 与用户裁决「进度与盈亏相关联」）**：**解锁条件依然与账户盈亏无关**——任何余额、任何章末评级都能解锁该章的品种与词典条目，这一层不变。盈亏影响的是**章末的推进方式**（进阶加演 / 常规 / 补救节拍，见 `### 章末结算与评级`）与**结业评定**，**不影响解锁**。**解锁看理解，推进看成绩，毕业看两样都过——这就是本作的三层分工。**

七类品种全部在框架内，但**按理解程度逐层放出**（Koster 渐进曲线 + 难度曲线公平性 + chunking）。

| 层 | 解锁内容 | v1.0 门槛 | **v2.0 载体（章节）** | 教学顺序理由 |
|----|---------|----------|---------------------|-------------|
| **L0 开场即开放** | A 股 + 概念词典 + 老周 | 无 | **第一章**（开户、入金、第一单、首次复盘） | 最贴近中国小白日常，规则中等，是「入市第一课」本意 |
| **L0+** | A 股规则深化 | — | **第二章**（四类拒单、限价/市价、板块联动） | 规则的边界必须亲手撞过才记得住 |
| **L1** | ETF + 公募基金（场外） | 完成新手链（首笔买卖 + 一次复盘） | **第三章** | ETF 是 A 股延伸；基金是「懒人投资」最常用，先建立稳健观念 |
| **L1+（机构）** | 无新交易品种；解锁**机构知识层**与词典的 `交易所/清算交收/监管/停牌/退市/黑天鹅` 条目 | — | **第四章** | 兑现 goal 的「交易所、银行等相关知识」；作为节奏呼吸章；为 L2 的跨境做认知准备 |
| **L2** | 港股 | 理解 T+1 与涨跌停后 | **第五章** | 引入汇率、无涨跌停、每手股数不固定——难度 +1 |
| **L3** | 美股 | 理解港股后 | **第六章** | 零佣金、时差、碎股、无涨跌停（熔断）——再加时区与「不在场风险」 |
| **L4** | 加密货币 | 理解前序市场风险后 | **第七章** | 7×24、极高波动、无监管——风险教育高潮，须后置；且必须带「先写下底线」的仓位教学 |
| **L5 最后** | 期权 | 通过「期权理解小考」 | **第八章**（8.7 即原小考，保留） | 杠杆 + 时间衰减 + 归零，最复杂最危险，放最后且设门槛 |
| **毕业** | 全部解锁 + 自由模式全开 + 词典全条目 | 走完全部章节 + 理解确认 | **尾声** | 任何余额、任何评级都能毕业；结业评定三档只改变证书上的一行字与 E.2 的措辞 |

> 每个门槛仍是「**确认理解**」而非淘汰：答错只循环讲解，不阻断进度（no dead-end）。**v2.0 强化**：确认失败时文案是「我们再摆一次」，绝不用「重试 / 答错 / 失败」。
> **v2.1 补充**：**评级不是门槛。** 它是「本章走完之后多出来的一段」（A 是加演、D 是补救），**从不拦在解锁之前**。实现者不得把评级接进 `Unlock Progression` 的任何一行。

### Daily Review / Debrief（每日复盘）

当日 / 整局结束时玩家看到的：

- **当日盈亏** = `NAV_end − NAV_start_of_day`。
- **拆解**：`已实现盈亏（卖出/到期）` + `未实现盈亏变动（持仓市值变化）` + `费用支出`。
- **归因**：按「标的 × 事件 × 操作类型（追高/抄底/持有/止损）」分类展示。例：「你今日亏损主要来自：持有 X 期间遭遇利空新闻 Y。」
- **净值曲线**：累计 NAV 折线图（代码绘制）。
- **导师一句话点评** + 相关概念回顾链接。
- **教学定位**：复盘不是「你输了」，而是「你今天学到：新闻对价格的影响」。

> **v2.0 新增（线性主线的增益）**：复盘多一行**「与本章的关系」**——「你在这一章学的 `T+1`，就是你刚才为什么卖不掉的原因」。线性结构让复盘能说出一句 v1.0 说不出来的话：**这一笔亏损，正好是这一章想让你学会的东西。** 这句话是全作最强的一次「教学即玩法」的兑现。
>
> **章末复盘与每日复盘的区分**：每日复盘是日日可看的轻量面板（v1.0 原样保留）；**章末复盘**是每章结束时的一次完整收束（这一章你做了什么、懂了什么、留下的问题是什么），比每日复盘更长、更有仪式感。
>
> **v2.1 新增：「章末复盘」与「章末结算」是两块不同的面板，不得合并**：
> - **章末复盘**（原有）——**不评价盈亏好坏**，只回答「你懂了什么」。
> - **章末结算**（v2.1 新增）——**只回答「你这一章把钱管成什么样」，且只用公开的公式说话**，不做道德评价。它包含四行：① 三项输入的计算过程（`rar` / `maxDD` / `costRatio`，逐项展开，公式与阈值可查）；② 分数 `S` 与评级 A/B/C/D；③ **「本章大盘同期涨跌（对照，不计分）」一行**，若跑赢则额外给出一行肯定；④ 下一章怎么走（加演 / 常规 / 补救）。**第一章与第四章不显示该面板，只在章目标卡上写明「本章不打分」。**
> - 这样切分的原因：**「懂没懂」和「做得好不好」是两件事**，把它们混在一张面板里会让玩家把所有讲解都读成评价（`player-motivation.md`：焦虑破坏 flow）。

### Win / Lose / No-End Conditions（胜负与无死局）

- **Win（毕业）**：走完八章 + 每章理解确认 + 尾声（结业证书场景）。**判定不看账户余额**——亏了 ¥30,000 但走完全程、能讲清每一类品种的玩家，与赚了 ¥30,000 的玩家拿到同一张结业证书。无分数赢家，只有「毕业」。
  - **v2.1 新增的第二层**：证书上有一行**结业评定**（优秀 / 良好 / 结业，三档都是毕业），由六次章末评级与全程调整后累计收益决定（见 `### 章末结算与评级`）。**它只改变证书上的一行字与 E.2 的措辞，不改变任何解锁、任何内容、任何后续可玩性。**
- **Lose**：本作**不设传统「输 / Game Over」**。为保留目标感，设「风险警示线」：当 `NAV < 初始本金(¥100,000) × 10% = ¥10,000`（或现金近 0 且重仓深度套牢）时，触发**风险警示**而非结束——游戏继续。
  - **语义（v2.0 起，v2.1 沿用）**：触警时**暂停章内节拍推进**，插入一个**「补救节拍」**——老周带玩家把「钱是怎么少的」逐层拆开看（哪个标的、哪条事件、哪次操作、哪些费用），给出补救建议与**「一键补足本金」**，然后把玩家送回主线（回到被打断的那个节拍）。**补救节拍不改变章节进度、不改变已解锁内容**，同一章最多触发一次（与 D 级补救共用配额）。
- **成绩不佳的新语义（v2.1，取代「钱完全不影响你」）**：**章末评级为 D 不是失败**——它是「这一章我们再摆一次」：老周换一种说法把「钱是怎么少的」重讲一遍，讲完照常确认、照常推进。**D 不不扣任何东西：不掉钱、不掉进度、不掉解锁、不掉老周的态度、不改变下一章的任何参数。** 它唯一改变的是**你多听了一段讲解**（以及结业评定里的一个 B 变 A 的机会少了）。
- **章内失误的新语义（v2.0 起）**：某个节拍没做出来（例如产品对比选错、理解确认答错）**不是失败**——老周**换一种说法重讲一遍**，节拍重来。文案必须写成「我们再摆一次」，禁止出现「重试 / 答错 / 关卡失败 / 重玩」。**没有重玩关卡，只有再讲一次。**
- **失败教什么**：被拒单、亏损、触警、评级 D 全部转为**教学事件**（安全失败），不终止游戏、不扣进度。
- **No-Dead-End 规则（无死局，v2.1 全部保留并加固）**：
  1. 模拟资金可「**一键补足本金**」（`cash += ¥100,000 − NAV`，持仓与历史全保留）或「**重置账户**」（清空持仓 + `cash = ¥100,000`），**不限次数、不惩罚、不需要理由**。
  2. 即使重仓归零，账户仍允许补足/重置，**永远能继续学习**；黄档（NAV < ¥50,000）时章目标卡常驻补足入口，红档（NAV < ¥10,000）时补救节拍末尾强制给出入口。
  3. 任何亏损都附「复盘与补救建议」，并把玩家送回可学习状态（章内触警回到被打断的节拍；章末 D 级完成补救节拍后确认）。
  4. **已学概念、已解锁进度、已完成的章节确认、老周的关系推进、净值曲线历史**永不丢失（即使补足本金或重置账户）。
  5. 玩家在**纯自由模式 / 自由交易日窗口**里无论做什么（包括故意把账户玩归零），都**不会影响任何章节进度、解锁状态或任何一次章末评级**。
  6. **v2.1 新增**：**评级永不构成死局的条件**——任何余额在任何一章都能离开该章（补救节拍必过），任何评级都能走到尾声（三档评定都是毕业）。

> **心理安全论证（v2.1 修订）**：本作不是真钱游戏。若惩罚过重，小白学到的是「恐惧」而非「literacy」（见 D-5）。因此失败必须 instructive 而非 demoralizing。
> **v2.0 的论证是「进度不看钱」；v2.1 换成「钱只决定怎么走，不决定能不能走」**——这是同一份心理安全承诺的**更弱化、更受限的版本**：允许盈亏说话，但剥夺它所有"卡人"的权力（不发资源、不改市场、不挡解锁、不挡毕业）。
> **同时必须承认新出现的压力**：用户批准「进度与盈亏相关联」后，玩家会第一次担心「我是不是亏太多了」。因此必须保证：① 评级公式公开、运气可见（「跑赢市场」行）；② D 级只有帮助、没有剥夺；③ 补足本金随时可用且被正常化；④ 三档评定都是毕业。这四条共同构成 v2.1 的「**你亏得起，也永远走得完**」承诺。

### Characters

#### 导师（周老师 / 老周）
见「学习系统 → 导师角色」与「线性主线设计 → 导师在主线里的行为」。**v2.0 中他不再只是一个对话框**：前四章他以「在场的人」出现（有自己的场景、自己的动作、自己的沉默），第五章起退为**随时可呼出的声音与头像**。玩家不操控 avatar，他以立绘 + 对白 + 提问的形式陪伴。
**v2.1：他没有隐藏层。** 用户裁决「导师不要隐藏」——全剧没有反转、没有秘密、没有延迟揭晓。他为什么只教「看懂规则」和「不要预测」？他**会直接说出来**：「因为在这八章里，你没有一次能提前知道明天的新闻。这不是我藏着什么，这是市场本身的样子。」他的弧线讲的是**功能的变化**（牵引 → 松手 → 退后 → 直言 → 敬畏 → 交还），不是身份的秘密。

#### 玩家（主角）
**第二人称的「你」**：毕业三年、一线城市工作、月薪约 ¥9,000、三年攒下 ¥100,000 的普通成年人。**无具象 avatar、无立绘、无姓名、无性别标注**。第一视角操作券商 App，被故事以「你」称呼。

- 有**给定的处境**（舅舅总在家庭群转发财经小道消息、同事爱晒收益、家人反对、室友去香港、同学劝你炒币），但**没有给定的性格**——玩家自己的反应就是主角的反应。
- 这个设定的取舍见 `## 线性主线设计 → 主角` 与决策日志 D-21。
- **不写内心独白**，只写「你看到了什么」「别人对你说了什么」「你做了什么」。玩家的情绪由玩家自己填，这是第二人称叙事的基本纪律。

### Game Flow

| 阶段 | 内容 |
|------|------|
| **Start state** | 一行开场声明（「真规则、假钱、¥100,000」）→ 银行大厅 → 开户 → 入金 → 第一章节拍 1.4（看行情） |
| **主线推进** | 章 → 章内节拍 → **章末结算（评级 A/B/C/D → 加演 / 常规 / 补救）** → 章末确认 → 自由交易日窗口 → 下一章。共八章 + 尾声 |
| **随时可切** | 全局菜单可在「章内模式 / 自由交易日窗口 / 纯自由模式」之间切换（见 `## 线性主线设计 → 主线与自由交易工具如何共存`） |
| **Win condition** | 见上「Win（毕业）」——走完八章 + 理解确认 + 尾声，**不看账户余额**；结业评定三档都是毕业 |
| **Lose condition** | 见上「Lose / No-Dead-End」——无真正失败；风险警示线与 D 级评级都只触发补救节拍 |
| **After win（毕业后）** | 自由模式全开：全部七类品种、全部词典条目、无目标卡与引导；老周退场但仍可随时呼出（语气更像朋友）。可回看全程净值曲线、**六次章末评级记录**与复盘报告 |
| **补足本金 / 重置资金** | 任何时候可用（黄档起在章目标卡常驻入口）；只改变资金与持仓，**不影响章节进度、解锁、词典、老周关系与净值历史**；**均视为外来入金，从评级与结业评定口径中剔除** |

### Map / Level Design（场景构成）

本作**无传统可探索关卡地图**。线性结构的「关卡」是**章**，场景插画是章的舞台与教学氛围来源（均为 AI 生成位图；含文字的部分一律由代码绘制）。

**场景 = 章之舞台，其切换由剧情节点与教学节点触发**：

| 场景 | 出现章节 | 叙事 / 教学用途 |
|------|---------|---------------|
| **银行大厅**（scene_bank） | 第一章（1.1） | 「存款 vs 投资」「银行 vs 券商」；玩家在这里第一次与老周对话 |
| **导师办公室**（scene_office） | 第一、二、四章；以及玩家主动呼叫老周时的默认场景 | 温暖安静；桌上一杯热咖啡与绿植（**v2.1：日常道具，无第二层含义**） |
| **交易大厅 / 交易楼层**（scene_trading_floor） | 第二章（2.4–2.5）、第五章（5.4）、第六章（6.4）、第七章（7.3） | 波动与风险的情绪场；每出现一次，波动强度上一个台阶 |
| **交易所大厅**（scene_exchange） | 第四章（4.1–4.4） | 市场生态、撮合、清算交收；**本章为独立场景章** |
| **深夜书桌 / 客厅**（scene_late_night，**v2.0 新增**） | 第六章（6.1–6.6）、第七章（7.1–7.2） | 「你一个人对着屏幕」的情绪场；承载「钱不睡觉，但我得睡」 |
| **咖啡馆**（scene_cafe，**v2.0 新增**） | 第三章开场、第八章开场、尾声 | 老周与玩家的「平等对话」场；他从办公室走到咖啡馆，是他从「老师」变成「朋友」的视觉信号（两杯饮品 = **他给你也点了一杯**，温暖的日常，**v2.1：不含任何伏笔**） |
| **结业证书场景**（scene_graduation） | 尾声 | 毕业仪式；**v2.1：这一场承载的是「你走过的每一章」与期末净值的对照，不再是任何人的揭示** |

> **场景的使用纪律**：① 场景是氛围，不是可探索地图；② 每个场景最多承担 2–3 个节拍，避免长时间停留在同一张背景上（`player-motivation.md`：Easy Fun 需要新鲜感）；③ **券商 App 界面本身是最常出现的「场景」**——它才是本作真正的主舞台，所有场景插画都是为了给这个界面提供「你为什么打开它」的理由。
>
> 画面内不含可读文字。

| D-30 | 「回合制交易日」的去留 | ①保留为全局唯一节奏（v1.0）②降为章内节拍推进器并取消沙盒节奏 ③**双层运行** | **③双层运行**：章内它是节拍推进器（老周说「明天再看」），自由窗口/自由模式里回到 v1.0 的完全自主语义 | 回合制是 D-2 的核心决策（去时间焦虑、Explorer 型玩家的自主节奏、flow），撤销它会破坏已实现并已测试的整套运行时。**交易日设计本身不做任何修改**，只是被主线赋予了第二层含义（从「玩家的自由节奏」变成「故事的一拍」） |
| D-31 | 章节数量、时长与会话形状 | ①少章长篇（4–5 章）②多章短篇（12+ 章）③**八章 + 尾声** | **③八章 + 尾声**：单章 15–25 分钟（第四章机构章 12–15 分钟，作为呼吸章），每章 3–5 个节拍、2–3 个自然停顿点，全程约 3–4 小时 | 章数与品种分布对齐（7 类品种 + 1 个机构章 + 尾声）。①会让单章篇幅超过一次会话能承受的量；②会让每章只有一个概念，缺少「处境升级」的弧线。**停顿点纪律**：每 5–8 分钟必须有一个停顿点，并显示「本章还剩 X 个节拍」（`player-motivation.md`：入门者最怕「不知道还要多久」）。呼吸章（第四章）的存在是为了给第五章的难度跃升蓄力（难度曲线公平性） |
| D-32 | 事件池的跨市场缺口如何处理 | ①改写现有 20 件事件以覆盖多市场 ②为 HK/US/CRYPTO 新增事件组 ③**保持 20 件不动，明确声明 v1 缺口** | **③（v1）+ 建议 v2 采用 ②** | 本版受约束不得改写事件文案、不得重新设计事件池。事实：20 件的 `market` 全为 `A_SHARE`，因此港股/美股/加密/期权四章在 v1 **没有专属新闻卡**，这四章以「行情引擎的自然波动 + 叙述性情境」承载，通用宏观事件（M01/M02/M03/P01，`targets=["ALL"]`）只影响 A 股标的，可作旁证但不能作主事件。**此为需用户知悉的 v1 已知缺口，建议 v2 为 HK/US/CRYPTO 各补一组事件（新增，不改现有 20 件）** |
| D-33 | 触发风险警示线时主线如何处理 | ①仅显示警示，主线照常推进 ②**暂停章内节拍，插入「补救节拍」** ③结束当前章 | **②** | 带着恐慌继续走主线会让玩家把「学习」和「亏损」绑定（`player-motivation.md`：焦虑破坏 flow，Serious Fun 变为恐惧）。补救节拍把「钱是怎么少的」逐层拆开（标的 × 事件 × 操作 × 费用），并把玩家**送回可学习状态**；它不改变章节进度、不改变已解锁内容。③等于变相 Game Over，违反 D-5 |
| D-34 | 章内失误的文案与重来语义 | ①重试 / 答错 / 关卡失败 ②**「我们再摆一次」** | **②** | 线性结构引入了一个 v1 没有的失败感来源：玩家会担心「我是不是卡住了」。因此**禁止出现「重试 / 答错 / 失败 / 重玩」四类字样**；一律写成「我们再摆一次」，由老周换一种说法重讲。**没有重玩关卡，只有再讲一次**——这是 D-5 心理安全在线性结构下的具体化 |
| D-35 | 为线性主线新增的美术资产 | ①复用现有 7 项 ②新增场景与表情 | **②新增 3 项**：`scene_cafe`（咖啡馆，仪式感：老周从「老师」变「朋友」）、`scene_late_night`（深夜书桌，承载「你一个人对着屏幕」）、`chapter_card`（章节完成卡，8 张）；**导师表情集新增 2 态**：示弱·为难 / 告别·释然；另增 `mentor_distant`（侧影/背影，用于他退场后） | 线性主线需要**场景之间有可辨识的情绪差异**——同一背景在四个不同情绪的场景里出现会失去叙事功能（`player-motivation.md`：Easy Fun 需要新鲜感）。**硬约束**：全部新素材的画面内不含可读文字（所有文字由代码绘制），`chapter_card` 的标题与文字由代码叠加 |
| D-36 | 概念词典是否随主线扩充 | ①保持原 7 组条目 ②**按章节教学点补齐** | **②补齐**（新增 `场内 vs 场外`、`未知价交易`、`交易成本`、`存管`、`汇率折算`、`熔断`、`盘前/盘后`、`碎股`、`仓位管理`、`纪律`、`幸存者偏差`、`买卖价差`、`流动性`、`止盈止损`、`实值/虚值/平值`、`机会成本` 等） | 章节教学设计里出现的每一个概念都必须在词典里查得到（`Done When`：词典覆盖 GDD 中列出的全部概念）。**不删除任何原有条目**，只增补 |
| **D-37**（v2.1 新增） | 盈亏关联进度的**具体形态** | ①每个节拍都看钱 ②只做结局评定 ③**章末评级（A/B/C/D）+ 三项钱口径输入** | **③章末一次评级**，输入为 `rar`（章内调整收益）、`maxDD`（章内最大回撤）、`costRatio`（章内成本比，分母为成交金额）；`S = clamp(50 + rar×833, 0, 100) − 40×f(maxDD) − 15×f(costRatio)`；A `S≥80` / B `60–79` / C `40–59` / D `<40`。**第一、四章不评级；自由窗口与自由模式不计入评级；全剧共 7 次。** | **为什么是「章末」而不是「每笔」**：每笔交易都打分会让玩家不敢动手（`player-motivation.md`：焦虑破坏 flow），而只在结局打分又无法在过程中产生任何反馈（`core-frameworks.md`：loop 的 Reward 必须可见）。章末是**唯一既能形成反馈、又不打断操作节奏**的位置。**为什么输入是三项而不是单看收益**：①单看收益会把「大起大落回到原点」判成中性，而它其实是本作最想教的一种失败；②加上成本项使「费用是确定的、收益是不确定的」这条教学点被真实记账（`Realism vs Legibility` #12）；③回撤与成本两项都有硬上限，避免单次灾难拖垮后续（锁 L5）。**为什么分母用成交金额**：使费用惩罚只反映交易习惯、与资金量无关，从结构上掐断「穷玩家被固定佣金惩罚」这条隐性螺旋。 |
| **D-38**（v2.1 新增） | 如何防止「赢→更富→更易→更赢 / 输→更穷→更难→更输」的正反馈死循环 | ①回避需求（= v2.0）②接受螺旋、靠难度调参缓解 ③**接受需求并主动设计五把锁** | **③ 五把锁**：**L1 同章相对口径**（`rar`/`maxDD` 相对本章起点净值，绝不相对初始 ¥100,000——切断累积劣势，翻盘在结构上永远可能）；**L2 评级不改变市场**（不影响行情、事件抽取、事件幅度、费率、涨跌停、撮合、最小单位）；**L3 评级不给资源**（A 级只给内容与见证，不发钱/折扣/加成）；**L4 弱者得帮助**（D 级触发必过的补救节拍；黄档成本罚分 ×0.5）；**L5 上限与压缩**（`S` clamp 在 [0,100]，收益项 ±6% 饱和，罚分上限 40/15）。另有结构性保证：本作无保证金、无融资、费率不随资金量变化，且 `rar` 是百分比——**财富不产生任何机械优势**。 | 用户明确要求盈亏算数，而 `feedback-loops.md` 明确警告「rich get richer」型正反馈会导致「游戏过早失去平衡」。**正确做法不是拒绝需求，而是给需求装上限制器**——theory 给出的四条解法（配负反馈 / cosmetic rewards / limit magnitude / help the laggard）在本设计里被逐条落成 L1–L5。**L1 是最关键的一条**：它把「越亏越难」从**难以修复的累积状态**降级为**每章重置的相对量**，这是整个防御的地基。 |
| **D-39**（v2.1 新增） | 玩家亏光/亏损时的**恢复路径** | ①只保留重置账户 ②触警即结束 ③**三级资金阶梯 + 一键补足本金 + 外来入金剔除口径** | **③**：绿档 `NAV ≥ ¥50,000` 正常；黄档 `¥10,000 ≤ NAV < ¥50,000` 章目标卡常驻「补足本金」入口 + 成本罚分 ×0.5；红档 `NAV < ¥10,000` 强制补救节拍 + 末尾强提示补足。**「一键补足本金」= `cash += ¥100,000 − NAV`，持仓/历史/进度/解锁/词典全部保留，不限次数、不惩罚、老周把它正常化（「这是训练场，不是成绩单」）。** 与既有「重置账户」并存。**关键口径：补足与重置都算「外来入金」，从 `rar` 与结业累计收益中剔除。** | **No-Dead-End 的 v2.1 版本必须比 v2.0 更强**，因为引入了评级压力。`feedback-loops.md` 的核心原则是「**Provide help to laggards rather than punishing leaders**」「Resource compensation」，因此补足本金是**补偿**而非施舍。**「外来入金剔除」是这套设计里最不能省的一条**：若剔除它，补足本金立刻变成刷分手段（亏了就补、补了不扣），「盈亏算数」与「心理安全」两个目标会同时崩塌。三级阶梯则保证玩家在任何余额下都能**在两步之内**回到可学习状态。 |
| **D-40**（v2.1 新增） | 移除导师揭示后，**叙事重量的去向** | ①换一个反转 ②放弃情感落点 ③**转移到玩家自己的弧线** | **③**：原 E.2「老周的故事」改为 **E.2「你走过的每一章」**——一章一个画面 + 一句「你在那一章说过或做过的话」+ 那一章的评级；**最后一屏把第一章那张活期存单（1.5% vs 2%）与「如果这八章你什么也没做」的推算值，并排放在你真实的期末净值旁边**。另加**六次章末评级记录表**（真实盈亏，不美化）与**章末「你还记得吗」回响**（老周引用玩家自己在更早章节说过/做过的事）。 | **纪律：不得用任何其他反转/秘密/延迟揭晓替补这份重量**（用户明确要求「导师不要隐藏」）。**为什么 ③ 比 ② 更好**：`player-motivation.md` 的 Serious Fun 来自「用游戏改变自己」，而改变必须**可见**。原方案靠「别人的故事」让玩家回望；新方案靠「玩家自己的数字」让玩家回望——**后者不但不可替代（反转只有一次，这笔账只有他有），而且是真的**。活期存单的对照屏同时兑现了第一章 1.1 节拍埋下的 `通胀侵蚀购买力`，使全剧首尾闭环**由玩家自己的账完成**，而不是由任何人的秘密完成。 |
| **D-41**（v2.1 新增） | 结局如何体现账户表现，同时让亏光的玩家仍能毕业 | ①无差别证书 ②按盈亏分档但低档不算毕业 ③**三档评定，全部都是毕业** | **③ 结业评定：优秀**（六次评级 `A ≥ 4` 且全程调整后累计收益 `> 0`）/ **良好**（`A + B ≥ 4`）/ **结业**（其余全部情形，**含亏光与反复补足本金**）。三档都解锁全部七类品种与自由模式、都拿到结业证书、都能进入 E.4。**差别只在**证书上的一行字、E.2 里老周念出的措辞、以及评级记录表的完整呈现。 | 调和用户的**两项同时成立**的要求：「账户表现要在结局里被看见」与「no dead end 是绝对的」。若低档不算毕业（②），则等于用破产取消毕业资格，直接违反 D-5 与 No-Dead-End；若无差别（①），则等于盈亏在结局里消失，违反用户裁决。**③ 的做法是把「毕业」与「评定」分成两件事**：毕业是**资格**（只看理解，D-1 不变），评定是**记录**（看盈亏）。这也符合 D-1 的原始判断——胜利是理解；评定只是理解之外的一份**诚实记录**。 |

## Realism vs Legibility（写实 vs 易读 显式声明）

凡本作**刻意不等于真实市场**之处，均已在此与决策日志（D-3、D-10、D-11、D-12）标明：

1. 期权：弃用 Black-Scholes / 波动率曲面 / 美式行权 / 实物交割，改用欧式现金交割 + 线性时间衰减透明模型。
2. 行情：以可解释事件驱动，不模拟真实随机游走；微量噪声可见。
3. 部分成交：默认不发生。
4. `avgCost` 不含费；费率、最小变动价位、交易时段均为教学近似值。
5. 做空 / 融资融券 / 期权卖方：本作不开放（小白保护），仅作风险提示。
6. 汇率：由事件透明驱动、玩家可见，非真实浮动市场。
7. **【v2.0 新增】剧情时序占位**：为了把八章串成一条线，主线会指定「你现在大约在开局的第几周」「你在这一章大约是几月」。这个时间感是**叙事便利**，不等同于真实市场的季节性与日历效应；游戏内真正的日期与交易日历仍由既有 Calendar 决定，不因叙事而改变。
8. **【v2.0 新增】人物的时间压缩**：八章的剧情跨度在叙事上是数月，但玩家实际只经历数十个「交易日」。因此人物关系与生活事件（换工作、室友去香港）在叙事时间上被压缩。**这是刻意的时间压缩**，目的是让「学习曲线」与「生活事件」同步，而不是模拟真实人生的时间尺度。
9. **【v2.0 新增】章节内的「引导式成功」**：第一章从开场到第一单成交之间不存在可能失败的交互，这是**刻意的入门保护**，不等于真实开户体验（真实开户有 KYC、风险测评、密码器、银证转账等待）。本作把这一段的复杂度折叠成一次点击，是为了不在前五分钟劝退小白。真实开户流程的关键名词仍在第一章的词典与对白中出现。
10. **【v2.0 新增】老周是虚构人物，他的建议不构成投资建议**：他是叙事装置与教学角色，台词中不给出针对真实标的的买卖建议。他所有的「建议」都是教学性的（「先写下你能接受亏多少」而不是「买这只」）。
11. **【v2.1 新增】章末评级是游戏构造，不是投资能力认证**：`S` 的三项输入与阈值都是为教学设计的近似值（例如成本比的分母用成交金额而非本金、`±6%` 饱和、回撤罚分的 5%/20% 拐点），**不对应任何真实的业绩评价体系**。结业评定（优秀 / 良好 / 结业）**只描述这个模拟账户的这八章**，不构成任何形式的投资能力判断或资质。游戏内需在结业评定面板上明写这句话。
12. **【v2.1 新增】评级让「费用」被真实记账，因此也被刻意放大教学**：评级把章内累计费用除以成交金额作为一个独立输入，会让「高频小额交易」的代价在分数上显形（小额 A 股买单的固定佣金占比可达 0.8%）。**这是刻意的教学放大**——真实账户里这笔钱同样在流失，只是没人给你算出来。为避免它变成对穷玩家的结构性惩罚，配套三条：分母用成交金额（与资金量无关）、黄档罚分减半、老周在补救节拍里明说这是固定费用的性质而非玩家的错。
13. **【v2.1 新增】自由模式与评级的边界**：`rar`/`maxDD`/`costRatio` **只统计章内官方节拍期间**。自由交易日窗口与纯自由模式的盈亏**不进评级**（沙盒保持干净），但**进**结业评定的「全程调整后累计收益」。这是一处刻意的不对称：**沙盒里的行为不改变你怎么走，但会被如实记进你自己的成绩单。**

> 目的：让小白**先建立正确心智模型**，而非被真实复杂度吓退。日后若需「进阶真实模式」，可在框架上叠加，不破坏教学层。
>
> **v2.0 提示**：线性主线新增的 7–10 条简化，与 1–6 条性质不同——1–6 简化的是**市场机制**，7–10 简化的是**叙事与引导**。前者的目的是「建立正确心智模型」，后者的目的是「保证初学者撑得过前二十分钟」。二者都必须被玩家与实现者知悉。
>
> **v2.1 提示**：11–13 条又属第三类——它们简化（并刻意放大）的是**「成绩」这件事本身**。前两类的目的是「别被复杂度吓退」与「别在前二十分钟劝退」，这一类的目的是**「让盈亏说得上话，但不让它卡住任何人」**。三条的共同前提是：**评级公式全程公开、对玩家可查**（`game-fairness.md`：不得有隐藏机制）。
